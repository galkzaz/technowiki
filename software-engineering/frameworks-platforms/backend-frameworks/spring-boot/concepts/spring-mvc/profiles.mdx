title: Profiles

---
Spring profiles can be used to specify the environment-specific configuration, which,
in this case, is a configuration that is only to be used when running the microservice
in a Docker container. Other examples are configurations that are specific to dev,
test, and production environments. Values in a profile override values from the
default profile. By using YAML files, multiple Spring profiles can be placed in the
same file, separated by `---`.
