Spring MVC handles HTTP request lifecycle in enterprise applications.

---
## Request Flow
1. DispatcherServlet receives request
2. Handler mapping finds controller
3. Controller processes request
4. Service layer executes logic
5. Response returned

---
## Controller Example
```java
@RestController
@RequestMapping("/users")
public class UserController {
    @GetMapping("/{id}")
    public User getUser(@PathVariable Long id) {
        return new User(id, "John");
    }
}
