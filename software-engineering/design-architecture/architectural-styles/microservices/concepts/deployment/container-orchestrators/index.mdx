A container engine, such as Docker, is not enough to be able to use containers in a pro-
duction environment. Something is needed that can ensure that all the containers are up
and running and that can scale out containers on a number of servers, thereby providing
high availability and increased compute resources.

These types of products became known as container orchestrators. A number of prod-
ucts have evolved over the last few years, such as Apache Mesos, Docker in swarm mode,
Amazon ECS, HashiCorp Nomad, and Kubernetes.
