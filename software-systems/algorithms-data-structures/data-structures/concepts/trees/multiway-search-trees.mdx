title: Self-Balancing Trees
description: Self-Balancing Trees
---

Data is traditionally stored in magnetic disks that read data in
big chunks. In these cases, the B-Tree, a generalization of Binary
Trees, is used. In B-Trees, nodes may store more than one item and
can have more than two children, making it efficient to operate
with data in big chunks.
