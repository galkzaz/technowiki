A **tree** is a hierarchical, non-linear data structure made of nodes connected by edges.

Unlike arrays (linear) or linked lists (sequential), trees model parent → child relationships

Trees are especially suitable for hierarchical data, such as a file directory structure, or the command chain of an army.

Widely used in:
- File systems
- Compilers (AST)
- Databases (B-Trees)
- Networking (routing)

## Terminology

Like the **Linked List**, the **Tree** employs memory cells that do not need to be contiguous in physical memory to store objects. Cells also have pointers to other cells. Unlike Linked Lists, cells and their pointers are not arranged as a linear chain of cells, but as a tree-like structure. 

Think of a tree like an inverted real tree:
```
        A
       / \
      B   C
     / \   \
    D   E   F
```
Core Terms
| Term    | Meaning                                  |
| ------- | ---------------------------------------- |
| Root    | Top node (A)                             |
| Node    | Each element (A, B, C, …)                |
| Edge    | Connection between nodes                 |
| Parent  | Node with children (A is parent of B, C) |
| Child   | Nodes below a parent                     |
| Leaf    | Node with NO children (D, E, F)          |
| Sibling | Nodes with same parent (B, C)            |
| Subtree | Tree rooted at any node                  |
| Degree  | Number of children                       |
| Path    | Sequence of nodes                        |

In the Tree terminology, a cell is called a **node**, and a pointer from
one cell to another is called an **edge**. 

The topmost node of a tree
is the *Root* Node: the only node that doesn’t have a parent. Apart
from the Root Node, **nodes in trees must have exactly one parent**(If a node violates this rule, many search algorithms for trees won’t work.).

Two nodes that have the same parent are **siblings**. A node’s
parent, grandparent, great-grandparent (and so on all the way to
the Root Node) constitute the node’s **ancestors**. Likewise, a node’s
children, grandchildren, great-grandchildren (and so on all the way
to the bottom of the tree) are the node’s **descendants**.

Nodes that do not have any children are **leaf** nodes (think of
leaves in an actual tree ). And a **path** between two nodes is a set
of nodes and edges that can lead from one node to the other.

And finally, a set of trees can be referred to as a forest.

## Height & Depth
A node’s **level** is the size of its path to the Root Node. The tree’s
**height** is the level of the deepest node in the tree. 

Depth: Number of edges from root → node 

Height: Number of edges from node → deepest leaf 

Example:
```
level 0        A        (height = 2) 
              / \
level 1      B   C      (height = 1)
            /
level 2    D            (height = 0)
```
- Depth of D = 2 
- Height of A = 2 

Key Formula

Height of tree:
$$
h=max depth 
$$$

Why Important?
- Determines time complexity 
    - Balanced trees → O(log n) 
    - Skewed trees → O(n) 
## Binary Trees
A **Binary Tree** is a tree where each node has **at most two children**:
- **Left child** 
- **Right child** 

Conceptual View:
```
        A
       / \
      B   C
     / \   \
    D   E   F
```

Useful in heaps, BSTs, expression trees

**Node Structure (C)**
```c
typedef struct Node {
    int data;
    struct Node* left;
    struct Node* right;
} Node;
```
This is the **core memory model**.

Each node stores: 
- Data 
- Pointer to left child 
- Pointer to right child

**Memory Layout Insight**

Unlike arrays:
- Nodes are not contiguous 
- Connected via pointers (addresses) 
```
[Node A] → left → [Node B]
         → right → [Node C]
```
### Properties of Binary Trees
- Max nodes at level $i = 2^i$
- Max nodes in tree of height h: $2^(h+1)−1$
- Min Height for n Nodes: $h=log⁡2(n)$

This is why balanced trees are fast

### Types of Binary Trees
#### Strict (Full) Binary Tree
Every node has 0 or 2 children
```
      A
     / \
    B   C
   / \
  D   E
```
- Valid
- Node with 1 child is NOT allowed

#### Complete Binary Tree
- All levels filled except possibly last
- Last level filled left to right
```
      A
     / \
    B   C
   / \  /
  D  E F
```
Used in Heaps

#### Perfect Binary Tree
Completely filled tree
- All internal nodes have 2 children 
- All leaves at same level 
```
      A
     / \
    B   C
   / \ / \
  D  E F  G
```
Key Formula (Perfect Tree)
$$
Nodes(N)=2^(h+1)−1 
$$

#### Skewed Binary Tree
Degenerates into a linked list
```
A
 \
  B
   \
    C
```

Worst-case performance = O(n)
🔥 Comparison Table
| Type     | Rule                | Shape       |
| -------- | ------------------- | ----------- |
| Full     | 0 or 2 children     | Flexible    |
| Complete | Filled left → right | Almost full |
| Perfect  | Completely full     | Symmetric   |

## Binary Tree Traversals
Traversal = visiting all nodes in a specific order.

These define how you process the tree.

Example:
```
      A
     /  \
    B    C
   / \  /
  D   E F
```

### Depth-First Search (DFS)

#### Preorder (Root → Left → Right)
Visit root first
```
A → B → D → E → C → F
```
```c
void preorder(Node* root) {
    if (!root) return;
    printf("%d ", root->data);
    preorder(root->left);
    preorder(root->right);
}
```
Use cases:
- Copying tree 
- Prefix expression (compiler) 

##### Inorder (Left → Root → Right)
For Binary Search Trees, gives sorted order
```
D → B → E → A → C → F
```
```c
void inorder(Node* root) {
    if (!root) return;
    inorder(root->left);
    printf("%d ", root->data);
    inorder(root->right);
}
```
#### Postorder (Left → Right → Root)
Root visited last
```
D → E → B → F → C → A
```
```c
void postorder(Node* root) {
    if (!root) return;
    postorder(root->left);
    postorder(root->right);
    printf("%d ", root->data);
}
```
Use cases:
- Deleting tree 
- Evaluating expressions 

### Breadth-First Search(BFS) (Level Order) 

Level by level

Uses a queue
```
A → B → C → D → E → F
```

Uses:
- Shortest path 
- Serialization 

```c
void levelOrder(Node* root) {
    Queue q;
    enqueue(&q, root);

    while (!isEmpty(&q)) {
        Node* curr = dequeue(&q);
        printf("%d ", curr->data);

        if (curr->left) enqueue(&q, curr->left);
        if (curr->right) enqueue(&q, curr->right);
    }
}
```
### Traversal Patterns (C-style Pseudocode)
```c
void preorder(Node* root) {
    if (!root) return;
    visit(root);
    preorder(root->left);
    preorder(root->right);
}
void inorder(Node* root) {
    if (!root) return;
    inorder(root->left);
    visit(root);
    inorder(root->right);
}
void postorder(Node* root) {
    if (!root) return;
    postorder(root->left);
    postorder(root->right);
    visit(root);
}
```

## Implementation Approaches
There are **two main implementation approaches**:
1. **Pointer-Based** (Linked Structure) 
2. **Array-Based** (Implicit Tree) 

Both represent the same logical tree—but very differently in memory.

### Pointer-Based (Linked Structure)
Each node explicitly stores pointers to its children.

Structure is explicit
```
Node → left pointer → child
```
**C Code**
```c
typedef struct Node {
    int data;
    struct Node* left;
    struct Node* right;
} Node;
```
**Memory View**
```
[Node A] ──→ left ──→ [Node B]
         └─→ right ─→ [Node C]
```
Nodes can be anywhere in memory

**Characteristics**
| Feature       | Behavior          |
| ------------- | ----------------- |
| Memory        | Non-contiguous    |
| Shape         | Flexible          |
| Access        | Pointer traversal |
| Insert/Delete | Easy              |
| Overhead      | Extra pointers    |

**Advantages**
- Flexible: Works for any tree shape
- Dynamic size: Dynamic (easy to grow/shrink)
- Natural for recursion
- Used in:
    - Binary Trees
    - BST
    - AVL / Red-Black

**Disadvantages**
-Extra memory (2 pointers per node)
- Cache-unfriendly

### Array-Based (Implicit Tree)
Store tree in an array using index relationships, No explicit pointers.

Structure is implicit: Index math defines relationships.

**Index Rules:**

For node at index i:
| Node        | Index       |
| ----------- | ----------- |
| Root        | 0           |
| Left child  | 2i + 1      |
| Right child | 2i + 2      |
| Parent      | (i - 1) / 2 |

**Example**:

```
Tree:              Array:

        10          [10, 8, 9, 3, 5, 6]
       /  \
      8    9
     / \  /
    3  5  6
```

**Memory View**
```
Index:   0  1  2  3  4  5
Array:   A  B  C  D  E  F
```
Fully contiguous memory

**Characteristics**
| Feature       | Behavior         |
| ------------- | ---------------- |
| Memory        | Contiguous       |
| Shape         | Must be complete |
| Access        | Index arithmetic |
| Insert/Delete | Structured       |
| Overhead      | Minimal          |

**Advantages**
- Very memory efficient
- Cache-friendly (fast)
- No pointers needed
- Perfect for: Heaps (priority queues) 

**Disadvantages**
- Only works well for complete trees
- Wastes space if tree is sparse
- Harder to do arbitrary insert/delete

**Side-by-Side Comparison**
| Feature       | Pointer-Based  | Array-Based        |
| ------------- | -------------- | ------------------ |
| Structure     | Explicit links | Implicit via index |
| Memory        | Scattered      | Contiguous         |
| Flexibility   | High           | Low                |
| Best for      | BST, AVL       | Heap               |
| Insert/Delete | Easy           | Restricted         |
| Cache         | Poor           | Excellent          |

**Performance Insight**

**Pointer-Based**
- More flexible 
- Slower due to: 
    - Pointer chasing 
    - Cache misses 

**Array-Based**
- Faster in practice 
- Because: 
    - Sequential memory 
    - Better CPU cache usage

**Deep Insight (System-Level Thinking)**

This is really about:
| Concept      | Pointer-Based | Array-Based    |
| ------------ | ------------- | -------------- |
| Memory Model | Linked        | Indexed        |
| CPU Behavior | Cache misses  | Cache friendly |
| Control      | Dynamic       | Arithmetic     |

**When to Use Each**

**Use Pointer-Based When:**
- Tree is irregular 
- You need: 
    - BST 
    - AVL / Red-Black 
    - Expression trees 

**Use Array-Based When:**
- Tree is complete 
- You need: 
    - Heap 
    - Priority queue

## Trees vs Heaps
A **Heap** is a specialized type of **Binary Tree**

But not every tree is a heap.
| Structure   | Meaning                            |
| ----------- | ---------------------------------- |
| Tree        | General hierarchical structure     |
| Binary Tree | Each node ≤ 2 children             |
| Heap        | **Special Binary Tree with rules** |

So, Tree → Binary Tree → Heap (special case)

Heaps are trees stored as arrays.

A Heap is a Binary Tree with TWO strict properties:
1. Shape Property

    Must be a Complete Binary Tree
    - All levels full except last 
    - Last level filled left → right 
    ```
            10
          /  \
          8    9
        / \  /
        3  5  6
    ```
2. Heap Property

    Two types:
    
    1. Max Heap: Parent ≥ Children
    ```
            10
          /  \
          8    9
        / \  /
        3  5  6
    ```
    2. Min Heap: Parent ≤ Children
    ```
            3
          / \
          5   6
        / \
        8   9
    ```

Trees vs Heaps (Core Differences)
| Feature  | Binary Tree | Heap              |
| -------- | ----------- | ----------------- |
| Shape    | Any         | Complete only     |
| Ordering | None        | Parent-child rule |
| Search   | O(n)        | O(n)              |
| Insert   | Flexible    | Structured        |
| Delete   | Complex     | Efficient (root)  |

**Why Heaps Use Trees**

1. **Reason 1**: Hierarchy

    Heap operations depend on parent-child relationships:
    - Compare parent with children 
    - Move up/down (heapify) 

2. **Reason 2**: Logarithmic Height

    Because heap is complete: $h≈log2​n$, this Guarantees:
    - Insert → O(log n) 
    - Delete → O(log n)

**Why Not Use General Trees?**

Because:
| Problem          | General Tree        |
| ---------------- | ------------------- |
| No shape control | Can become skewed ❌ |
| Height           | O(n) ❌              |
| No ordering      | Inefficient ❌       |


Heap fixes all of these:
- Balanced shape 
- Log height 
- Structured comparisons

**Real-World Connection**

Heaps = Priority Queues

Used in:
- OS scheduling 
- Dijkstra’s algorithm 
- Event simulation 

Trees = General Modeling

Used in:
- File systems 
- Syntax trees 
- Databases

## Tree Operations
Tree operations are the core algorithms that let you manipulate and analyze trees.

All tree operations follow this pattern:
```
operation(root):
    if (!root) return

    operate(root)
    operation(root->left)
    operation(root->right)
```
This is Divide & Conquer

### Insertion

**Case 1: General Binary Tree**

No strict ordering → insert level-order (BFS)

**Idea**:
- Fill tree left to right 
- Keep it complete-like 

**Algorithm**:
1. Use a queue 
2. Find first node with missing child 
3. Insert there 

```c
Node* insert(Node* root, int value) {
    Node* newNode = createNode(value);
    if (!root) return newNode;
    Queue q;
    enqueue(&q, root);
    while (!isEmpty(&q)) {
        Node* curr = dequeue(&q);
        if (!curr->left) {
            curr->left = newNode;
            return root;
        } else enqueue(&q, curr->left);
        if (!curr->right) {
            curr->right = newNode;
            return root;
        } else enqueue(&q, curr->right);
    }
}
```
**Case 2: Binary Search Tree (Important)**

Maintains order:
- Left < Root < Right 

```c
Node* insertBST(Node* root, int value) {
    if (!root) return createNode(value);
    if (value < root->data)
        root->left = insertBST(root->left, value);
    else
        root->right = insertBST(root->right, value);
    return root;
}
```

### Deletion

**Case 1: General Binary Tree**

Strategy:
1. Find node to delete 
2. Replace with deepest node 
3. Delete deepest node 

**Case 2: BST Deletion**
3 Cases:

1. **Case 1**: Leaf node
    - Delete directly

2. **Case 2**: One child
    - Replace node with child

3. **Case 3**: Two children
    - Replace with:
        - Inorder successor (smallest in right subtree) 

```c
Node* findMin(Node* root) {
    while (root->left) root = root->left;
    return root;
}
Node* deleteBST(Node* root, int key) {
    if (!root) return NULL;
    if (key < root->data)
        root->left = deleteBST(root->left, key);
    else if (key > root->data)
        root->right = deleteBST(root->right, key);
    else {
        // Case 1 & 2
        if (!root->left) return root->right;
        if (!root->right) return root->left;
        // Case 3
        Node* temp = findMin(root->right);
        root->data = temp->data;
        root->right = deleteBST(root->right, temp->data);
    }
    return root;
}
```
### Searching
**General Binary Tree**

Must scan entire tree → O(n)
```c
int search(Node* root, int key) {
    if (!root) return 0;
    if (root->data == key) return 1;
    return search(root->left, key) || search(root->right, key);
}
```

**Binary Search Tree**

Efficient:
```c
int searchBST(Node* root, int key) {
    if (!root) return 0;
    if (key == root->data) return 1;
    if (key < root->data)
        return searchBST(root->left, key);
    else
        return searchBST(root->right, key);
}
```

### Height Calculation

Critical for performance
```c
int height(Node* root) {
    if (!root) return -1;
    int left = height(root->left);
    int right = height(root->right);
    return 1 + (left > right ? left : right);
}
```
Complexity:
- Always: O(n) 

### Finding Minimum / Maximum
**General Tree**
👉 Must traverse all → O(n)

**Binary Search Tree**

Efficient:
```c
Node* findMin(Node* root) {
    while (root->left)
        root = root->left;
    return root;
}
Node* findMax(Node* root) {
    while (root->right)
        root = root->right;
    return root;
}
```
### Counting Nodes
```c
int countNodes(Node* root) {
    if (!root) return 0;
    return 1 + countNodes(root->left) + countNodes(root->right);
}
```
### Leaf Count
```c
int countLeaves(Node* root) {
    if (!root) return 0;
    if (!root->left && !root->right) return 1;
    return countLeaves(root->left) + countLeaves(root->right);
}
```
### Tree Copy (Clone)
```c
Node* copyTree(Node* root) {
    if (!root) return NULL;
    Node* newNode = createNode(root->data);
    newNode->left = copyTree(root->left);
    newNode->right = copyTree(root->right);
    return newNode;
}
```
### Tree Deletion (Free Memory)

Use Postorder
```c
void deleteTree(Node* root) {
    if (!root) return;
    deleteTree(root->left);
    deleteTree(root->right);
    free(root);
}
```

#include <stdio.h>
#include <stdlib.h>
#include <limits.h> // For INT_MIN/INT_MAX
#include <stdbool.h> // For bool type
#include <math.h> // For abs

// Define the Node structure for the binary tree
typedef struct Node {
    int data;
    struct Node* left;
    struct Node* right;
} Node_t;

// --- Queue for Level Order Traversal/Insertion ---
// Basic linked list queue implementation for tree nodes
typedef struct QNode {
    Node_t* data;
    struct QNode* next;
} QNode_t;

typedef struct Queue {
    QNode_t* front;
    QNode_t* rear;
} Queue_t;

// Function to create a new queue node
QNode_t* createQNode(Node_t* node) {
    QNode_t* new_q_node = (QNode_t*)malloc(sizeof(QNode_t));
    if (!new_q_node) {
        perror("Memory allocation failed for QNode");
        exit(EXIT_FAILURE);
    }
    new_q_node->data = node;
    new_q_node->next = NULL;
    return new_q_node;
}

// Function to initialize an empty queue
void initQueue(Queue_t* q) {
    q->front = NULL;
    q->rear = NULL;
}

// Function to check if the queue is empty
bool isEmpty(Queue_t* q) {
    return q->front == NULL;
}

// Function to add a node to the queue
void enqueue(Queue_t* q, Node_t* node) {
    QNode_t* new_q_node = createQNode(node);
    if (q->rear == NULL) { // If queue is empty
        q->front = new_q_node;
        q->rear = new_q_node;
    } else {
        q->rear->next = new_q_node;
        q->rear = new_q_node;
    }
}

// Function to remove a node from the queue
Node_t* dequeue(Queue_t* q) {
    if (isEmpty(q)) return NULL;
    QNode_t* temp = q->front;
    Node_t* data = temp->data;
    q->front = q->front->next;
    if (q->front == NULL) { // If last element was dequeued
        q->rear = NULL;
    }
    free(temp); // Free the queue node, not the tree node
    return data;
}

// Function to free all QNodes in the queue (does not free tree nodes)
void freeQueue(Queue_t* q) {
    while (!isEmpty(q)) {
        dequeue(q);
    }
}
// --- End Queue ---

// 1. Node Creation
// Function to create a new tree node
Node_t* createNode(int data) {
    Node_t* newNode = (Node_t*)malloc(sizeof(Node_t));
    if (!newNode) {
        perror("Memory allocation failed for Node");
        exit(EXIT_FAILURE);
    }
    newNode->data = data;
    newNode->left = NULL;
    newNode->right = NULL;
    return newNode;
}

// 2. Insertion (Level Order for General Binary Tree)
// Inserts a new node into the first available spot using level-order traversal.
// This keeps the tree 'complete-like' and prevents skewing for general binary trees.
Node_t* insertNode(Node_t* root, int data) {
    Node_t* newNode = createNode(data);
    if (!root) {
        return newNode; // If tree is empty, new node becomes root
    }

    Queue_t q;
    initQueue(&q);
    enqueue(&q, root);

    while (!isEmpty(&q)) {
        Node_t* current = dequeue(&q);

        if (!current->left) {
            current->left = newNode;
            freeQueue(&q); // Free remaining queue nodes
            return root;
        } else {
            enqueue(&q, current->left);
        }

        if (!current->right) {
            current->right = newNode;
            freeQueue(&q); // Free remaining queue nodes
            return root;
        } else {
            enqueue(&q, current->right);
        }
    }
    freeQueue(&q); // Should not be reached if tree is successfully inserted
    return root;
}

// Preorder: Root -> Left -> Right
void preorderTraversal(Node_t* root) {
    if (root == NULL) return;
    printf("%d ", root->data);
    preorderTraversal(root->left);
    preorderTraversal(root->right);
}

// Inorder: Left -> Root -> Right
void inorderTraversal(Node_t* root) {
    if (root == NULL) return;
    inorderTraversal(root->left);
    printf("%d ", root->data);
    inorderTraversal(root->right);
}

// Postorder: Left -> Right -> Root
void postorderTraversal(Node_t* root) {
    if (root == NULL) return;
    postorderTraversal(root->left);
    postorderTraversal(root->right);
    printf("%d ", root->data);
}

// Level Order (BFS): Level by Level
void levelOrderTraversal(Node_t* root) {
    if (root == NULL) return;

    Queue_t q;
    initQueue(&q);
    enqueue(&q, root);

    while (!isEmpty(&q)) {
        Node_t* current = dequeue(&q);
        printf("%d ", current->data);

        if (current->left) {
            enqueue(&q, current->left);
        }
        if (current->right) {
            enqueue(&q, current->right);
        }
    }
    freeQueue(&q);
}

// 4. Search
// Searches for a value in the tree using level-order traversal (BFS).
// For a general binary tree, any traversal results in O(N) complexity in worst case.
bool searchTree(Node_t* root, int key) {
    if (root == NULL) return false;

    Queue_t q;
    initQueue(&q);
    enqueue(&q, root);

    while (!isEmpty(&q)) {
        Node_t* current = dequeue(&q);
        if (current->data == key) {
            freeQueue(&q);
            return true;
        }

        if (current->left) {
            enqueue(&q, current->left);
        }
        if (current->right) {
            enqueue(&q, current->right);
        }
    }
    freeQueue(&q);
    return false;
}

// 5. Get Height
// Calculates the height of the tree (number of edges from root to deepest leaf).
// Height of an empty tree is -1, height of a single node tree is 0.
int getHeight(Node_t* root) {
    if (root == NULL) {
        return -1; // Height of an empty tree is -1
    }
    int leftHeight = getHeight(root->left);
    int rightHeight = getHeight(root->right);
    return 1 + (leftHeight > rightHeight ? leftHeight : rightHeight);
}

// 6. Delete Entire Tree (Memory Free)
// Deletes all nodes in the tree using post-order traversal to free memory.
void deleteTree(Node_t* root) {
    if (root == NULL) return;

bool isSameTree(Node_t* p, Node_t* q) {

        return true; // Both are empty, considered same
    }
    if (p == NULL || q == NULL) {
        return false; // One is empty, the other is not
    }
    // Check current nodes and recursively check children
    return (p->data == q->data &&
            isSameTree(p->left, q->left) &&
            isSameTree(p->right, q->right));

// Mirrors the tree (swaps left and right children recursively).

    if (root == NULL) {
        return NULL;
    }
    Node_t* left = mirrorTree(root->left);
    Node_t* right = mirrorTree(root->right);

    // Swap the left and right pointers
    root->left = right;
    root->right = left;
    return root;
}

// 13. Check Balanced (isBalanced)
// Helper function to check balance and return height. -1 indicates unbalanced.
// Returns height of the subtree (number of edges) if balanced, -1 otherwise.
int checkHeightAndBalance(Node_t* node) {
    if (!node) return 0; // Height of an empty subtree is 0 (0 edges)

    int left_height = checkHeightAndBalance(node->left);
    if (left_height == -1) return -1; // Left subtree is unbalanced

    int right_height = checkHeightAndBalance(node->right);
    if (right_height == -1) return -1; // Right subtree is unbalanced

    if (abs(left_height - right_height) > 1) return -1; // Current node is unbalanced

    // Return height of the current subtree (edges)
    return 1 + (left_height > right_height ? left_height : right_height);
}

// Checks if the tree is height-balanced (difference between heights of left and right subtrees is at most 1).
bool isBalanced(Node_t* root) {
    return checkHeightAndBalance(root) != -1;
}

// 14. Diameter
// Helper function to calculate the maximum depth from a node downwards (number of nodes),
// while simultaneously updating the overall tree diameter.
// Returns the maximum depth (number of nodes) from the current node to any leaf in its subtree.
int getDepthInNodesAndDiameter(Node_t* node, int* diameter) {
    if (node == NULL) {
        return 0; // An empty subtree has a depth of 0 nodes
    }

    int left_depth = getDepthInNodesAndDiameter(node->left, diameter);
    int right_depth = getDepthInNodesAndDiameter(node->right, diameter);

    // Calculate the diameter passing through the current node
    // This path is (max depth from left child) + (max depth from right child) + 1 (for current node)
    *diameter = fmax(*diameter, left_depth + right_depth + 1);

    // Return the maximum depth (number of nodes) from the current node downwards
    return 1 + fmax(left_depth, right_depth);
}

int getDiameter(Node_t* root) {
    int diameter = 0; // Initialize diameter (stores number of nodes in the longest path)
    getDepthInNodesAndDiameter(root, &diameter);
    return diameter;
}

    // This keeps the tree 'complete-like' and prevents skewing for general binary trees.
    public Node insertNode(Node root, int data) {
        Node newNode = new Node(data);
        if (root == null) {
            return newNode; // If tree is empty, new node becomes root
        }

        Queue<Node> q = new LinkedList<>();
        q.offer(root); // Add root to the queue

        while (!q.isEmpty()) {
            Node current = q.poll(); // Remove node from front of queue

            if (current.left == null) {
                current.left = newNode;
                return root;
            } else {
                q.offer(current.left); // Add left child to queue
            }

            if (current.right == null) {
                current.right = newNode;
                return root;
            } else {
                q.offer(current.right); // Add right child to queue
            }
        }
        return root; // Should not be reached if tree is successfully inserted
    }

    // 3. Traversals
    // Preorder: Root -> Left -> Right
    public void preorderTraversal(Node root) {
        if (root == null) return;
        System.out.print(root.data + " ");
        preorderTraversal(root.left);
        preorderTraversal(root.right);
    }

    // Inorder: Left -> Root -> Right
    public void inorderTraversal(Node root) {
        if (root == null) return;
        inorderTraversal(root.left);
        System.out.print(root.data + " ");
        inorderTraversal(root.right);
    }

    // Postorder: Left -> Right -> Root
    public void postorderTraversal(Node root) {
        if (root == null) return;
        postorderTraversal(root.left);
        postorderTraversal(root.right);
        System.out.print(root.data + " ");
    }

    // Level Order (BFS): Level by Level
    public void levelOrderTraversal(Node root) {
        if (root == null) return;

        Queue<Node> q = new LinkedList<>();
        q.offer(root);

        while (!q.isEmpty()) {
            Node current = q.poll();
            System.out.print(current.data + " ");

            if (current.left != null) {
                q.offer(current.left);
            }
            if (current.right != null) {
                q.offer(current.right);
            }
        }
    }

    // 4. Search
    // Searches for a value in the tree using level-order traversal (BFS).
    // For a general binary tree, any traversal results in O(N) complexity in worst case.
    public boolean searchTree(Node root, int key) {
        if (root == null) return false;

        Queue<Node> q = new LinkedList<>();
        q.offer(root);

        while (!q.isEmpty()) {
            Node current = q.poll();
            if (current.data == key) {
                return true;
            }

            if (current.left != null) {
                q.offer(current.left);
            }
            if (current.right != null) {
                q.offer(current.right);
            }
        }
        return false;
    }

    // 5. Get Height
    // Calculates the height of the tree (number of edges from root to deepest leaf).
    // Height of an empty tree is -1, height of a single node tree is 0.
    public int getHeight(Node root) {
        if (root == null) {
            return -1; // Height of an empty tree is -1
        }
        int leftHeight = getHeight(root.left);
        int rightHeight = getHeight(root.right);
        return 1 + Math.max(leftHeight, rightHeight);
    }

    // 6. Delete Entire Tree (Memory Free)
    // In Java, memory management is handled by the garbage collector.
    // Setting references to null allows eligible objects to be garbage collected.
    public void deleteTree(Node root) {
        // Explicit deletion is not required in Java.
        // The garbage collector will reclaim memory when no references point to nodes.
        // For demonstration, we could recursively set children to null, but it's often not necessary.
        // This method effectively performs nothing specific as GC handles memory.
        if (root == null) return;
        // The recursive calls below would typically be for other purposes like logging or custom cleanup.
        // For memory deallocation, Java's GC is sufficient.
        // For actual node removal, if we wanted to remove a *subtree* from a larger structure,
        // we would set the parent's reference to `null`.
        // E.g., if a parent `p` had `p.left = root;`, we would do `p.left = null;`
        // But here, 'delete entire tree' means removing the whole structure starting from `root`.
        // Setting `root = null;` in `main` is the actual 'deletion' of the tree reference.
    }

    // 7. Count Nodes
    // Counts the total number of nodes in the tree.
    public int countNodes(Node root) {
        if (root == null) {
            return 0;
        }
        return 1 + countNodes(root.left) + countNodes(root.right);
    }

    // 8. Count Leaf Nodes
    // Counts the number of leaf nodes (nodes with no children).
    public int countLeafNodes(Node root) {
        if (root == null) {
            return 0;
        }
        if (root.left == null && root.right == null) {
            return 1; // It's a leaf node
        }
        return countLeafNodes(root.left) + countLeafNodes(root.right);
    }

    // 9. Find Max / Min (General Tree)
    // Finds the maximum value in a general binary tree.
    // Requires traversing all nodes as there's no inherent order like in a BST.
    public int findMax(Node root) {
        if (root == null) {
            return Integer.MIN_VALUE; // Return smallest possible int if tree is empty
        }
        int maxVal = root.data;
        int leftMax = findMax(root.left);
        int rightMax = findMax(root.right);

        maxVal = Math.max(maxVal, Math.max(leftMax, rightMax));
        return maxVal;
    }

    // Finds the minimum value in a general binary tree.
    public int findMin(Node root) {
        if (root == null) {
            return Integer.MAX_VALUE; // Return largest possible int if tree is empty
        }
        int minVal = root.data;
        int leftMin = findMin(root.left);
        int rightMin = findMin(root.right);

        minVal = Math.min(minVal, Math.min(leftMin, rightMin));
        return minVal;
    }

    // 10. Copy Tree
    // Creates a deep copy of the given tree.
    public Node copyTree(Node root) {
        if (root == null) {
            return null;
        }
        Node newNode = new Node(root.data);
        newNode.left = copyTree(root.left);
        newNode.right = copyTree(root.right);
        return newNode;
    }

    // 11. Tree Equality (isSameTree)
    // Checks if two trees are structurally identical and have the same data in corresponding nodes.
    public boolean isSameTree(Node p, Node q) {
        if (p == null && q == null) {
            return true; // Both are empty, considered same
        }
        if (p == null || q == null) {
            return false; // One is empty, the other is not
        }
        // Check current nodes and recursively check children
        return (p.data == q.data &&
                isSameTree(p.left, q.left) &&
                isSameTree(p.right, q.right));
    }

    // 12. Mirror Tree
    // Mirrors the tree (swaps left and right children recursively).
    public Node mirrorTree(Node root) {
        if (root == null) {
            return null;
        }
        Node left = mirrorTree(root.left);
        Node right = mirrorTree(root.right);

        // Swap the left and right pointers
        root.left = right;
        root.right = left;
        return root;
    }

    // 13. Check Balanced (isBalanced)
    // Helper function to check balance and return height. -1 indicates unbalanced.
    // Returns height of the subtree (number of edges) if balanced, -1 otherwise.
    private int checkHeightAndBalance(Node node) {
        if (node == null) return 0; // Height of an empty subtree is 0 (0 edges)

        int leftHeight = checkHeightAndBalance(node.left);
        if (leftHeight == -1) return -1; // Left subtree is unbalanced

        int rightHeight = checkHeightAndBalance(node.right);
        if (rightHeight == -1) return -1; // Right subtree is unbalanced

        if (Math.abs(leftHeight - rightHeight) > 1) return -1; // Current node is unbalanced

        // Return height of the current subtree (edges)
        return 1 + Math.max(leftHeight, rightHeight);
    }

    // Checks if the tree is height-balanced (difference between heights of left and right subtrees is at most 1).
    public boolean isBalanced(Node root) {
        return checkHeightAndBalance(root) != -1;
    }

    // 14. Diameter
    // Wrapper class to pass diameter by reference (since int is primitive)
    private static class DiameterWrapper {
        public int diameter = 0;
    }

    // Helper function to calculate the maximum depth from a node downwards (number of nodes),
    // while simultaneously updating the overall tree diameter.
    // Returns the maximum depth (number of nodes) from the current node to any leaf in its subtree.
    private int getDepthInNodesAndDiameter(Node node, DiameterWrapper diameterWrapper) {
        if (node == null) {
            return 0; // An empty subtree has a depth of 0 nodes
        }

        int leftDepth = getDepthInNodesAndDiameter(node.left, diameterWrapper);
        int rightDepth = getDepthInNodesAndDiameter(node.right, diameterWrapper);

        // Calculate the diameter passing through the current node
        // This path is (max depth from left child) + (max depth from right child) + 1 (for current node)
        diameterWrapper.diameter = Math.max(diameterWrapper.diameter, leftDepth + rightDepth + 1);

        // Return the maximum depth (number of nodes) from the current node downwards
        return 1 + Math.max(leftDepth, rightDepth);
    }

    // Calculates the diameter of the tree (longest path between any two nodes).
    // The diameter is defined as the number of nodes in the longest path.
    public int getDiameter(Node root) {
        DiameterWrapper diameterWrapper = new DiameterWrapper();
        getDepthInNodesAndDiameter(root, diameterWrapper);
        return diameterWrapper.diameter;
    }

Notes:
- Java uses garbage collection, so there are no explicit `deleteTree` or `free` calls. Setting the `root` reference to `null` allows the entire tree structure to be garbage collected when no other references to its nodes exist.
- `java.util.Queue` implemented by `java.util.LinkedList` is used for BFS/level-order operations. `offer()` adds to the tail, `poll()` removes from the head.
- `Math.max()` and `Math.abs()` are standard utility functions.
- `Integer.MIN_VALUE` and `Integer.MAX_VALUE` are used for initial values in `findMax` and `findMin`.
- For `diameter` calculation, an inner `DiameterWrapper` class is used to simulate "pass by reference" for the `diameter` integer, as Java primitives are passed by value.

use std::rc::Rc;
use std::cell::RefCell;
use std::collections::VecDeque;
use std::cmp::{max, min};

// Define the Node structure for the binary tree
#[derive(Debug, PartialEq, Eq)]
pub struct Node {
    pub data: i32,
    pub left: Option<Rc<RefCell<Node>>>,
    pub right: Option<Rc<RefCell<Node>>>,
}

impl Node {
    // 1. Node Creation
    // Function to create a new tree node
    pub fn new(data: i32) -> Rc<RefCell<Self>> {
        Rc::new(RefCell::new(Node {
            data,
            left: None,
            right: None,
        }))
    }
}

pub struct GeneralBinaryTree;

impl GeneralBinaryTree {
    // 2. Insertion (Level Order for General Binary Tree)
    // Inserts a new node into the first available spot using level-order traversal.
    // This keeps the tree 'complete-like' and prevents skewing for general binary trees.
    pub fn insert_node(root: Option<Rc<RefCell<Node>>>, data: i32) -> Rc<RefCell<Node>> {
        let new_node = Node::new(data);
        if root.is_none() {
            return new_node; // If tree is empty, new node becomes root
        }

        let root_rc = root.unwrap();
        let mut queue = VecDeque::new();
        queue.push_back(Rc::clone(&root_rc));

        while let Some(current_rc) = queue.pop_front() {
            let mut current = current_rc.borrow_mut();

            if current.left.is_none() {
                current.left = Some(Rc::clone(&new_node));
                return root_rc;
            } else {
                queue.push_back(Rc::clone(current.left.as_ref().unwrap()));
            }

            if current.right.is_none() {
                current.right = Some(Rc::clone(&new_node));
                return root_rc;
            } else {
                queue.push_back(Rc::clone(current.right.as_ref().unwrap()));
            }
        }
        root_rc // Should not be reached if tree is successfully inserted
    }

    // 3. Traversals
    // Preorder: Root -> Left -> Right
    pub fn preorder_traversal(root: &Option<Rc<RefCell<Node>>>) {
        if let Some(node_rc) = root {
            let node = node_rc.borrow();
            print!("{} ", node.data);
            Self::preorder_traversal(&node.left);
            Self::preorder_traversal(&node.right);
        }
    }

    // Inorder: Left -> Root -> Right
    pub fn inorder_traversal(root: &Option<Rc<RefCell<Node>>>) {
        if let Some(node_rc) = root {
            let node = node_rc.borrow();
            Self::inorder_traversal(&node.left);
            print!("{} ", node.data);
            Self::inorder_traversal(&node.right);
        }
    }

    // Postorder: Left -> Right -> Root
    pub fn postorder_traversal(root: &Option<Rc<RefCell<Node>>>) {
        if let Some(node_rc) = root {
            let node = node_rc.borrow();
            Self::postorder_traversal(&node.left);
            Self::postorder_traversal(&node.right);
            print!("{} ", node.data);
        }
    }

    // Level Order (BFS): Level by Level
    pub fn level_order_traversal(root: &Option<Rc<RefCell<Node>>>) {
        if root.is_none() {
            return;
        }

        let mut queue = VecDeque::new();
        queue.push_back(Rc::clone(root.as_ref().unwrap()));

        while let Some(current_rc) = queue.pop_front() {
            let current = current_rc.borrow();
            print!("{} ", current.data);

            if let Some(left_rc) = &current.left {
                queue.push_back(Rc::clone(left_rc));
            }
            if let Some(right_rc) = &current.right {
                queue.push_back(Rc::clone(right_rc));
            }
        }
    }

    // 4. Search
    // Searches for a value in the tree using level-order traversal (BFS).
    // For a general binary tree, any traversal results in O(N) complexity in worst case.
    pub fn search_tree(root: &Option<Rc<RefCell<Node>>>, key: i32) -> bool {
        if root.is_none() {
            return false;
        }

        let mut queue = VecDeque::new();
        queue.push_back(Rc::clone(root.as_ref().unwrap()));

        while let Some(current_rc) = queue.pop_front() {
            let current = current_rc.borrow();
            if current.data == key {
                return true;
            }

            if let Some(left_rc) = &current.left {
                queue.push_back(Rc::clone(left_rc));
            }
            if let Some(right_rc) = &current.right {
                queue.push_back(Rc::clone(right_rc));
            }
        }
        false
    }

    // 5. Get Height
    // Calculates the height of the tree (number of edges from root to deepest leaf).
    // Height of an empty tree is -1, height of a single node tree is 0.
    pub fn get_height(root: &Option<Rc<RefCell<Node>>>) -> i32 {
        if root.is_none() {
            return -1; // Height of an empty tree is -1
        }
        let node = root.as_ref().unwrap().borrow();
        let left_height = Self::get_height(&node.left);
        let right_height = Self::get_height(&node.right);
        1 + max(left_height, right_height)
    }

    // 6. Delete Entire Tree (Memory Free)
    // In Rust, memory management for Rc/RefCell is handled automatically by reference counting.
    // When the last Rc pointing to a node is dropped, the node's memory is reclaimed.
    // To "delete" the tree, simply drop the Rc that holds the root.
    // This function explicitly consumes the Rc<RefCell<Node>> to decrement its ref count.
    // If this was the last strong reference, the memory will be freed.
    pub fn delete_tree(root: Option<Rc<RefCell<Node>>>) {
        if let Some(node_rc) = root {
            // Drop the Rc. If this was the last strong reference,
            // the node and its children (recursively) will be dropped.
            drop(node_rc);
        }
    }

    // 7. Count Nodes
    // Counts the total number of nodes in the tree.
    pub fn count_nodes(root: &Option<Rc<RefCell<Node>>>) -> i32 {
        if root.is_none() {
            return 0;
        }
        let node = root.as_ref().unwrap().borrow();
        1 + Self::count_nodes(&node.left) + Self::count_nodes(&node.right)
    }

    // 8. Count Leaf Nodes
    // Counts the number of leaf nodes (nodes with no children).
    pub fn count_leaf_nodes(root: &Option<Rc<RefCell<Node>>>) -> i32 {
        if root.is_none() {
            return 0;
        }
        let node = root.as_ref().unwrap().borrow();
        if node.left.is_none() && node.right.is_none() {
            return 1; // It's a leaf node
        }
        Self::count_leaf_nodes(&node.left) + Self::count_leaf_nodes(&node.right)
    }

    // 9. Find Max / Min (General Tree)
    // Finds the maximum value in a general binary tree.
    // Requires traversing all nodes as there's no inherent order like in a BST.
    pub fn find_max(root: &Option<Rc<RefCell<Node>>>) -> i32 {
        if root.is_none() {
            return i32::MIN; // Return smallest possible int if tree is empty
        }
        let node = root.as_ref().unwrap().borrow();
        let max_val = node.data;
        let left_max = Self::find_max(&node.left);
        let right_max = Self::find_max(&node.right);

        max(max_val, max(left_max, right_max))
    }

    // Finds the minimum value in a general binary tree.
    pub fn find_min(root: &Option<Rc<RefCell<Node>>>) -> i32 {
        if root.is_none() {
            return i32::MAX; // Return largest possible int if tree is empty
        }
        let node = root.as_ref().unwrap().borrow();
        let min_val = node.data;
        let left_min = Self::find_min(&node.left);
        let right_min = Self::find_min(&node.right);

        min(min_val, min(left_min, right_min))
    }

    // 10. Copy Tree
    // Creates a deep copy of the given tree.
    pub fn copy_tree(root: &Option<Rc<RefCell<Node>>>) -> Option<Rc<RefCell<Node>>> {
        if root.is_none() {
            return None;
        }
        let original_node = root.as_ref().unwrap().borrow();
        let new_node_rc = Node::new(original_node.data);
        let mut new_node = new_node_rc.borrow_mut();
        new_node.left = Self::copy_tree(&original_node.left);
        new_node.right = Self::copy_tree(&original_node.right);
        drop(new_node); // Drop mutable borrow before returning Rc
        Some(new_node_rc)
    }

    // 11. Tree Equality (is_same_tree)
    // Checks if two trees are structurally identical and have the same data in corresponding nodes.
    pub fn is_same_tree(p: &Option<Rc<RefCell<Node>>>, q: &Option<Rc<RefCell<Node>>>) -> bool {
        match (p, q) {
            (None, None) => true, // Both are empty, considered same
            (Some(_), None) | (None, Some(_)) => false, // One is empty, the other is not
            (Some(p_rc), Some(q_rc)) => {
                let p_node = p_rc.borrow();
                let q_node = q_rc.borrow();
                // Check current nodes and recursively check children
                p_node.data == q_node.data &&
                Self::is_same_tree(&p_node.left, &q_node.left) &&
                Self::is_same_tree(&p_node.right, &q_node.right)
            }
        }
    }

    // 12. Mirror Tree
    // Mirrors the tree (swaps left and right children recursively).
    // Note: This operation modifies the tree in place.
    pub fn mirror_tree(root: &Option<Rc<RefCell<Node>>>) {
        if let Some(node_rc) = root {
            let mut node = node_rc.borrow_mut();
            // Recursively mirror children first
            Self::mirror_tree(&node.left);
            Self::mirror_tree(&node.right);

            // Swap the left and right pointers
            let left_child = node.left.take();
            let right_child = node.right.take();
            node.left = right_child;
            node.right = left_child;
        }
    }

    // 13. Check Balanced (is_balanced)
    // Helper function to check balance and return height. -1 indicates unbalanced.
    // Returns height of the subtree (number of edges) if balanced, -1 otherwise.
    fn check_height_and_balance(node: &Option<Rc<RefCell<Node>>>) -> i32 {
        if node.is_none() {
            return 0; // Height of an empty subtree is 0 (0 edges)
        }

        let left_height = Self::check_height_and_balance(&node.as_ref().unwrap().borrow().left);
        if left_height == -1 {
            return -1; // Left subtree is unbalanced
        }

        let right_height = Self::check_height_and_balance(&node.as_ref().unwrap().borrow().right);
        if right_height == -1 {
            return -1; // Right subtree is unbalanced
        }

        if (left_height - right_height).abs() > 1 {
            return -1; // Current node is unbalanced
        }

        // Return height of the current subtree (edges)
        1 + max(left_height, right_height)
    }

    // Checks if the tree is height-balanced (difference between heights of left and right subtrees is at most 1).
    pub fn is_balanced(root: &Option<Rc<RefCell<Node>>>) -> bool {
        Self::check_height_and_balance(root) != -1
    }

    // 14. Diameter
    // Helper function to calculate the maximum depth from a node downwards (number of nodes),
    // while simultaneously updating the overall tree diameter.
    // Returns the maximum depth (number of nodes) from the current node to any leaf in its subtree.
    fn get_depth_in_nodes_and_diameter(node: &Option<Rc<RefCell<Node>>>, diameter: &mut i32) -> i32 {
        if node.is_none() {
            return 0; // An empty subtree has a depth of 0 nodes
        }

        let node_ref = node.as_ref().unwrap().borrow();
        let left_depth = Self::get_depth_in_nodes_and_diameter(&node_ref.left, diameter);
        let right_depth = Self::get_depth_in_nodes_and_diameter(&node_ref.right, diameter);

        // Calculate the diameter passing through the current node
        // This path is (max depth from left child) + (max depth from right child) + 1 (for current node)
        *diameter = max(*diameter, left_depth + right_depth + 1);

        // Return the maximum depth (number of nodes) from the current node downwards
        1 + max(left_depth, right_depth)
    }

    // Calculates the diameter of the tree (longest path between any two nodes).
    // The diameter is defined as the number of nodes in the longest path.
    pub fn get_diameter(root: &Option<Rc<RefCell<Node>>>) -> i32 {
        let mut diameter = 0; // Initialize diameter (stores number of nodes in the longest path)
        Self::get_depth_in_nodes_and_diameter(root, &mut diameter);
        diameter
    }
}

Notes:
- Rust's ownership system requires `Rc<RefCell<Node>>` for tree structures where nodes need to be shared (e.g., parent points to child, and child might point back or be referenced multiple times in a queue) and mutable.
    - `Rc` (Reference Counted) enables multiple owners for the same data.
    - `RefCell` allows mutable borrows of the data inside an `Rc` even when the `Rc` itself is immutable (required for interior mutability).
- `Option<Rc<RefCell<Node>>>` is used for nullable pointers (e.g., `left` or `right` children, or the root itself).
- `.as_ref().unwrap().borrow()` is a common pattern to access the data inside `Option<Rc<RefCell<Node>>>` for reading.
- `.as_ref().unwrap().borrow_mut()` is used for mutable access.
- `.take()` is used on `Option` to move out the value, leaving `None` in its place. This is crucial for operations like `insert_node` where `root` might change.
- `VecDeque` from `std::collections` acts as a double-ended queue for BFS.
- `std::cmp::max` and `std::cmp::min` are used for comparisons.
- `delete_tree` explicitly consumes the `Rc` of the root. When the last `Rc` for a `Node` is dropped, Rust's memory management will deallocate it and, recursively, its children if their `Rc`s also reach zero. This is a form of automatic memory management similar to garbage collection, but deterministic.
- Rust functions use `snake_case` naming convention. Helper functions for internal logic (`check_height_and_balance`, `get_depth_in_nodes_and_diameter`) are private (no `pub`).
