Question 1

You are given n jobs. Each job has:

processing time

deadline

penalty if late

Goal: schedule jobs to minimize total penalty.

What strategy?

✅ Answer:

👉 Greedy

Reason:
Sort jobs by penalty descending (or by deadline with a priority rule).
This is a classic greedy scheduling problem.

Trick:
Looks like DP because it's optimization — but greedy works.

Question 2

Given n integers, determine whether there exists a subset whose sum equals S.

n ≤ 200
S ≤ 10,000

Strategy?

✅ Answer:

👉 Dynamic Programming

Reason:
Subset Sum → overlapping subproblems
DP complexity O(nS) works since S is small.

Trick:
Looks exponential (subsets), but constraints suggest DP.

Question 3

Same Subset Sum problem, but now:

n ≤ 40
S can be very large (10^9)

Strategy?

✅ Answer:

👉 Backtracking or Branch & Bound

Reason:
S is huge → DP not feasible
n small → exponential search acceptable

Constraint size changes the strategy.

Question 4

Find the maximum profit path in a grid from top-left to bottom-right.
You can move only right or down.

Strategy?

✅ Answer:

👉 Dynamic Programming

Reason:
Overlapping subproblems
Optimal substructure

Classic DP table problem.

Question 5

You must explore all possible assignments of n tasks to n workers.
n = 20
Minimize total cost.

Strategy?

✅ Answer:

👉 Branch & Bound

Reason:
n! search space
Need pruning
Classic assignment problem

Trick:
DP possible via bitmask, but n=20 → 2^20 manageable
So both DP (bitmask) or B&B acceptable
Exam answer likely B&B.

Question 6

Given a graph with negative edge weights (no negative cycles), find shortest path.

Strategy?

✅ Answer:

👉 Dynamic Programming style relaxation (Bellman-Ford)

Reason:
Greedy (Dijkstra) fails with negative edges.

Trick:
Looks like greedy shortest path, but negative edges break it.

Question 7

Place k knights on a chessboard so that none attack each other.
Find ALL valid configurations.

Strategy?

✅ Answer:

👉 Backtracking

Reason:
All solutions required
Constraint satisfaction

Question 8

Given coin denominations, find minimum number of coins to make amount X.

Coins: arbitrary values (not canonical).

Strategy?

✅ Answer:

👉 Dynamic Programming

Reason:
Greedy fails for arbitrary denominations.

Trick:
Many students wrongly say Greedy.

Question 9

Find a Hamiltonian path in a graph.

Strategy?

✅ Answer:

👉 Backtracking

Or Branch & Bound if optimization involved.

Reason:
Exponential search over permutations.

Question 10

You are given a very large dataset (10^7 elements).
Find the kth smallest element.

Strategy?

✅ Answer:

👉 Divide & Conquer (Quickselect)

Reason:
Partition-based selection
Average O(n)

Trick:
Looks like sorting problem, but no need to fully sort.


Question 11

Knapsack problem:
n = 200
Capacity = 10^9

Strategy?

✅ Answer:

👉 Branch & Bound

Reason:
Capacity too large for DP (O(nW) impossible)

Constraint size decides strategy.

Question 12
