# Graph Coloring

Graph Coloring is a graph problem in which we assign colors (or labels) to vertices while ensuring that no two adjacent vertices have the same color.

Graph Coloring problems arise when you have a fixed amount of
“colors” (or any other set of labels), and you must assign each node
in the Graph a color. Nodes that are connected with an edge cannot
share the same color.

It is one of the important problems in graph theory and has applications in scheduling, register allocation, frequency assignment, and resource allocation.

## 1. What is Graph Coloring?

Given an undirected graph:

\\[ G = (V,E) \\]

We want to assign a color to every vertex such that:

\\[ (u,v)\in E \implies color(u)\neq color(v) \\]

In other words:

- Every vertex must receive a color.
- Two vertices connected by an edge must have different colors.
- Two vertices that are not connected may share the same color.

A coloring satisfying these conditions is called a valid vertex coloring (or proper coloring).

## 2. Important Terminology

| Term                 | Meaning                                                            |
| -------------------- | ------------------------------------------------------------------ |
| Vertex coloring      | Assigning colors to graph vertices.                                |
| Proper coloring      | A coloring where adjacent vertices have different colors.          |
| k-coloring           | A valid coloring using at most k colors.                           |
| k-colorable graph    | A graph that has a proper coloring using at most k colors.         |
| Chromatic number     | Minimum number of colors needed for a proper coloring.             |
| Chromatic polynomial | Counts the number of valid colorings for a given number of colors. |

### Chromatic Number

The chromatic number is denoted by:

\\[ \chi(G) \\]

It represents the minimum number of colors required to color a graph properly.

For example:

- A graph with no edges requires one color (assuming it has at least one vertex).
- A bipartite graph requires at most two colors.
- A triangle requires three colors.
- A complete graph with \\(n\\) vertices requires \\(n\\) colors.

For the previous example:

\\[ \chi(G)=3 \\]


## 4. Types of Graph Coloring

There are several variations worth understanding.

| Type            | Description                                                          |
| --------------- | -------------------------------------------------------------------- |
| Vertex coloring | Adjacent vertices must have different colors.                        |
| Edge coloring   | Edges sharing a vertex must have different colors.                   |
| Face coloring   | Adjacent regions in a planar embedding must have different colors.   |
| List coloring   | Each vertex has its own permitted list of colors.                    |
| Total coloring  | Both vertices and edges receive colors under additional constraints. |

For DSA, vertex coloring is the fundamental problem.

## 5. Important Graph Coloring Algorithms

Unlike BFS and DFS, graph coloring does not have one universally optimal algorithm. The appropriate approach depends on whether we need any valid coloring, a coloring with a fixed number of colors, or the minimum number of colors.

Here are the main algorithms and strategies.

### 5.1 Greedy Coloring

Polynomial time

The greedy algorithm assigns colors one vertex at a time.

For each vertex:

1. Examine the colors already assigned to its neighbors.
2. Find the smallest available color not used by those neighbors.
3. Assign that color to the vertex.
4. Continue until all vertices are colored.

Greedy coloring is simple and efficient, but it does not necessarily produce the minimum number of colors.

Its running time with an adjacency-list representation is approximately:

\\[ O(V+E) \\]

assuming colors are checked using a suitable data structure.

### 5.2 Backtracking Coloring

Backtracking explores possible color assignments.

For each vertex:

1. Try assigning an available color.
2. Check whether the assignment is valid.
3. If valid, continue with the next vertex.
4. If no color works, undo the previous assignment and try another.

This can find a valid coloring using a specified number of colors, if one exists.

Its worst-case running time is exponential.

### 5.3 DSATUR (Degree of Saturation)

DSATUR is a heuristic that chooses the next vertex based on the number of different colors already assigned to its neighbors.

The idea:

- Prioritize vertices with the highest saturation degree.
- Break ties using the vertex with the highest degree.
- Assign the smallest available color.

It often produces better colorings than ordinary greedy coloring.

### 5.4 Welsh-Powell Algorithm

Welsh-Powell is another greedy strategy.

1. Sort vertices by decreasing degree.
2. Select the highest-degree uncolored vertex.
3. Assign a color to it.
4. Assign the same color to as many non-adjacent uncolored vertices as possible.
5. Repeat using another color.

It is a heuristic, not an algorithm guaranteed to find the minimum coloring.

## 6. Complexity and NP-Completeness

This is one of the most important theoretical aspects of graph coloring.

We need to distinguish two problems:

| Problem                                                       | Complexity                   |
| ------------------------------------------------------------- | ---------------------------- |
| Find a valid coloring using at most 2 colors                  | Polynomial time              |
| Find a valid coloring using at most 3 colors                  | NP-complete decision problem |
| Find a valid coloring using at most k colors, for fixed k ≥ 3 | NP-complete                  |
| Find the minimum number of colors                             | NP-hard optimization problem |

Why is finding the minimum number of colors difficult?

Because the number of possible color assignments grows exponentially.

For a graph with \\(V\\) vertices and \\(k\\) available colors, there are:

\\[ k^V \\]

possible assignments before checking whether they are valid.

However, this does not mean every algorithm must examine all these assignments. Backtracking, pruning, symmetry breaking, and specialized algorithms can eliminate large portions of the search space.

Important distinction: The optimization problem of finding the chromatic number is NP-hard. The decision problem of determining whether a graph is 3-colorable is NP-complete.

### Example: Exam Scheduling

Suppose we have four exams:

- Mathematics
- Physics
- Chemistry
- Programming

If two exams have students in common, they cannot be scheduled at the same time.

We construct a graph:

- Each exam is a vertex.
- An edge connects exams that share students.
- Each color represents a time slot.

Graph coloring gives us a valid exam schedule while trying to minimize the number of time slots.

Let's connect graph coloring to the example in your text.

Suppose we have four cell towers.

- Each tower is represented by a vertex.
- An edge connects two towers if their signals can interfere.
- Each frequency is represented by a color.
- Connected towers must use different frequencies.

Suppose the available frequencies are:

| Color  | Frequency |
| ------ | --------- |
| Red    | 900 MHz   |
| Blue   | 1800 MHz  |
| Green  | 2100 MHz  |
| Yellow | 2600 MHz  |

The problem becomes:

1. Find a valid assignment of frequencies.
2. Determine whether three frequencies are sufficient.
3. Determine whether two frequencies are sufficient.
4. Find the minimum number of frequencies required.

The last question is equivalent to finding the graph's chromatic number.

Important: In real wireless networks, frequency planning can involve additional constraints such as bandwidth, signal strength, and reuse distance. Graph coloring is a simplified model of the interference problem.
