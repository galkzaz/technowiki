**Java Core APIs** are the standard libraries that Java provides for building applications.

If the **Java language** gives you the programming rules:

```java
class
interface
if
for
while
try
catch
switch
```

then the **Core APIs** give you ready-made classes and interfaces for actually doing useful work:

```java
String
List
Map
File
Path
LocalDate
Thread
Optional
Stream
HttpClient
BigDecimal
```

You normally don't implement these from scratch—you use the APIs provided by the JDK.

## Where Core APIs fit

A useful mental model is:

```text
                    Java
                      │
          ┌───────────┴───────────┐
          │                       │
    Java Language             Java Core APIs
          │                       │
          │                 ┌─────┴─────┐
          │                 │           │
       Syntax              java.lang   java.util
       Types               java.io     java.nio
       Classes             java.time   java.math
       Generics            java.net    java.sql
       Exceptions          ...
       Lambdas
       Modules
```

## What does "API" mean?

API means **Application Programming Interface**.

For example, Java's `String` class provides methods such as:

```java
String name = "Gamal";

int length = name.length();

boolean empty = name.isEmpty();

String upper = name.toUpperCase();
```

You don't need to know how `String.length()` is implemented internally.

You need to know its **contract**:

```text
String
 ├── length()
 ├── charAt()
 ├── substring()
 ├── contains()
 ├── equals()
 ├── hashCode()
 └── ...
```

That's what an API provides: **A defined interface through which your program interacts with functionality.**

## Core APIs vs third-party libraries

This distinction is important.

### Java Core API

Comes with the JDK:

```java
import java.util.ArrayList;
import java.time.LocalDate;
import java.nio.file.Path;
```

You don't need to add a Maven dependency for these.

### Third-party library

You normally add a dependency:

```xml
<dependency>
    <groupId>...</groupId>
    <artifactId>...</artifactId>
</dependency>
```

Examples:

```text
Spring
Hibernate
Jackson
JUnit
Guava
Apache Commons
```

So:

```text
JDK
 │
 └── Java Core APIs
       │
       ├── java.lang
       ├── java.util
       ├── java.io
       ├── java.nio
       ├── java.time
       ├── java.math
       ├── java.net
       └── ...
```

while:

```text
External ecosystem
 │
 ├── Spring
 ├── Hibernate
 ├── Jackson
 ├── JUnit
 └── ...
```

## The major Core API areas

### `java.lang`

This is the foundation.

Examples:

```java
Object
String
StringBuilder
Integer
Long
Double
Math
System
Runtime
Thread
Throwable
Exception
Class
```

Example:

```java
String name = "Gamal";

System.out.println(name);

int length = name.length();
```

Notice:

```java
String
System
```

don't require explicit imports.

Java automatically makes `java.lang` available.

### Collections

One of the largest and most important Core API areas is the **Collections Framework**.

It gives you data structures such as:

```java
List
Set
Map
Queue
Deque
```

and implementations:

```java
ArrayList
LinkedList
HashSet
TreeSet
HashMap
TreeMap
ArrayDeque
PriorityQueue
```

Example:

```java
List<String> names = new ArrayList<>();

names.add("Alice");
names.add("Bob");
names.add("Charlie");

for (String name : names) {
    System.out.println(name);
}
```

The important concepts here are:

```text
Collection
    │
    ├── List
    │     ├── ArrayList
    │     └── LinkedList
    │
    ├── Set
    │     ├── HashSet
    │     └── TreeSet
    │
    └── Queue
          ├── PriorityQueue
          └── Deque
```

And separately:

```text
Map
 ├── HashMap
 ├── LinkedHashMap
 ├── TreeMap
 └── ...
```

### Functional APIs

Java's functional programming APIs support:

```java
Function
Predicate
Consumer
Supplier
UnaryOperator
BinaryOperator
```

For example:

```java
List<Integer> numbers =
        List.of(1, 2, 3, 4, 5);

numbers.stream()
       .filter(n -> n % 2 == 0)
       .forEach(System.out::println);
```

Here several Core APIs work together:

```text
List
 ↓
Stream
 ↓
Predicate
 ↓
Consumer
```

This area includes:

```text
java.util.function
java.util.stream
```

and should cover:

```text
functional interfaces
lambdas
method references
streams
collectors
optional
```

Although **lambdas themselves are a language feature**, `Function`, `Predicate`, `Stream`, etc. are APIs.

### `java.io`

`java.io` provides traditional input/output APIs.

For example:

```java
File
InputStream
OutputStream
Reader
Writer
BufferedReader
BufferedWriter
```

Example:

```java
try (BufferedReader reader =
         new BufferedReader(new FileReader("data.txt"))) {

    String line;

    while ((line = reader.readLine()) != null) {
        System.out.println(line);
    }
}
```

Conceptually:

```text
Input
 │
 ├── InputStream
 └── Reader

Output
 │
 ├── OutputStream
 └── Writer
```

### `java.nio`

Modern Java I/O is largely based around **NIO**.

Important APIs include:

```java
Path
Paths
Files
ByteBuffer
Channel
```

Example:

```java
Path path = Path.of("data.txt");

String content = Files.readString(path);

System.out.println(content);
```

Instead of:

```text
File
```

you increasingly work with:

```text
Path
Files
```

### Date and Time

Modern Java date/time APIs are under:

```java
java.time
```

Important types include:

```java
LocalDate
LocalTime
LocalDateTime
ZonedDateTime
Instant
Duration
Period
ZoneId
```

Example:

```java
LocalDate today = LocalDate.now();

LocalDate birthday =
        LocalDate.of(1990, 5, 20);

Period age =
        Period.between(birthday, today);

System.out.println(age.getYears());
```

This is much better than teaching the old:

```java
java.util.Date
java.util.Calendar
```

as the primary date/time APIs.

### Mathematics

Java provides:

```java
Math
StrictMath
BigInteger
BigDecimal
```

For example:

```java
double result = Math.sqrt(25);

System.out.println(result);
```

For precise decimal calculations:

```java
BigDecimal price =
        new BigDecimal("19.99");

BigDecimal tax =
        new BigDecimal("0.15");

BigDecimal total =
        price.add(price.multiply(tax));

System.out.println(total);
```

This is especially important for financial applications.

### Regular Expressions

Java provides regex APIs through:

```java
java.util.regex
```

Main classes:

```java
Pattern
Matcher
```

Example:

```java
Pattern pattern =
        Pattern.compile("\\d+");

Matcher matcher =
        pattern.matcher("Order 123");

if (matcher.find()) {
    System.out.println(matcher.group());
}
```

### Networking

Java provides APIs for network communication.

Modern HTTP APIs include:

```java
java.net.http.HttpClient
java.net.http.HttpRequest
java.net.http.HttpResponse
```

Example:

```java
HttpClient client =
        HttpClient.newHttpClient();

HttpRequest request =
        HttpRequest.newBuilder()
                .uri(URI.create("https://example.com"))
                .GET()
                .build();
```

Then:

```java
HttpResponse<String> response =
        client.send(
            request,
            HttpResponse.BodyHandlers.ofString()
        );
```

### Concurrency

Java's Core APIs provide substantial concurrency functionality.

For example:

```java
Thread
Executor
ExecutorService
Future
CompletableFuture
Lock
Semaphore
CountDownLatch
ConcurrentHashMap
```

Example:

```java
ExecutorService executor =
        Executors.newFixedThreadPool(4);

executor.submit(() ->
    System.out.println("Running")
);

executor.shutdown();
```

### Reflection

Reflection allows a program to inspect classes at runtime.

Example:

```java
Class<String> clazz = String.class;

System.out.println(clazz.getName());

for (var method : clazz.getDeclaredMethods()) {
    System.out.println(method.getName());
}
```

Important APIs include:

```text
Class
Method
Field
Constructor
Modifier
```

This is useful for understanding frameworks such as Spring, Hibernate, and JUnit.

### Annotations

Java's annotation API allows metadata to be attached to program elements.

Example:

```java
@Override
public String toString() {
    return "Product";
}
```

Custom annotations:

```java
@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.TYPE)
@interface Entity {
}
```

Then:

```java
@Entity
class Product {
}
```

Annotations are interesting because there are **two different things**:

```text
Java language feature
        │
        ▼
Annotation syntax: @Something
        │
        ▼
Core API
        │
        ├── Annotation
        ├── Retention
        ├── Target
        └── ElementType
```

### SQL

Java also provides JDBC APIs:

```text
java.sql
javax.sql
```

Important interfaces include:

```java
Connection
Statement
PreparedStatement
ResultSet
Driver
DataSource
```

Example:

```java
Connection connection =
        dataSource.getConnection();

PreparedStatement statement =
        connection.prepareStatement(
            "SELECT * FROM products WHERE id = ?"
        );

statement.setLong(1, 10);
```

For a backend-oriented Java roadmap, JDBC deserves a significant section.

### Security

Java also provides security-related APIs.

Conceptually:

```text
Security
├── cryptography
├── keys
├── certificates
├── signatures
├── secure random
└── permissions
```

For example:

```java
SecureRandom random =
        new SecureRandom();

int value = random.nextInt();
```

## The Core APIs are interconnected

{/* The biggest thing I would emphasize in your documentation is that you shouldn't study each API as an isolated island. */}

Consider this example:

```java
Path path = Path.of("orders.txt");

List<String> orders =
        Files.readAllLines(path);

List<String> completed =
        orders.stream()
              .filter(line -> line.contains("COMPLETED"))
              .toList();

completed.forEach(System.out::println);
```

This tiny program uses several Core APIs:

```text
Path
 │
 └── java.nio.file

Files
 │
 └── java.nio.file

List
 │
 └── java.util

Stream
 │
 └── java.util.stream

Predicate
 │
 └── java.util.function

String
 │
 └── java.lang
```

## The key distinction

I'd use this hierarchy as your mental model:

```text
Java
│
├── Language
│   └── "How do I write Java?"
│
├── Core APIs
│   └── "What functionality does Java provide?"
│
├── JVM
│   └── "How does Java execute?"
│
└── Ecosystem
    ├── Spring
    ├── Hibernate
    ├── Maven / Gradle
    ├── JUnit
    └── ...
```

And inside **Core APIs**:

```text
Core APIs
│
├── java.lang       → fundamental Java types
├── Collections     → data structures
├── Functional      → lambdas/streams APIs
├── IO              → traditional I/O
├── NIO             → modern I/O/filesystem
├── Time            → dates/time/zones
├── Math            → numerical operations
├── Regex           → pattern matching
├── Networking      → network/HTTP APIs
├── Concurrency     → threads/executors/synchronization
├── Reflection      → runtime type inspection
├── Annotations     → metadata APIs
└── JDBC            → database access
```
