<Question>

If `i` and `j` are positive integers, does `(-i)/j` always have the same value as `-(i/j)`? Justify your answer.

</Question>
<Answer>

Yes. If i and j are positive integers in C (C99 and later), then
$$
(−i)/j=−(i/j)
$$
always holds.

Let’s justify this carefully.

1️⃣ C Integer Division Rule

In C99 and later, integer division truncates toward zero.

That means: a/b

produces the integer closest to zero.

Examples:
```
7 / 3  = 2
-7 / 3 = -2
```
Notice:
```
7 / 3  =  2.333 →  2
-7 / 3 = -2.333 → -2
```
Both results move toward zero.

2️⃣ Let i and j be Positive

Assume:
```
i > 0
j > 0
```

First compute:

i / j

Let

i / j = q

where q is the integer quotient after truncation.

3️⃣ Compute -(i/j)
```
-(i/j) = -q
```
4️⃣ Compute (-i)/j

Now consider:
```
(-i)/j
```
The exact real result is:

$$
-\frac{ij}{j} = −(i/j)
$$

But C truncates toward zero.

Since i/j truncates to q, the real value is:

$$
-(i/j) = -q - (r/j)
$$

where:  $0≤r<1$

Truncating toward zero removes the fractional part:
$$
(-i)/j = -q
$$
5️⃣ Compare Results

We found:

-(i/j) = -q
(-i)/j = -q

So:

(-i)/j == -(i/j)
6️⃣ Example

Let:

i = 7
j = 3

Compute both sides.

Left side
(-7)/3 = -2
Right side
-(7/3)
= -(2)
= -2

They match.

</Answer>
</QandA>

Only one of the expressions ++i and i++ is exactly the same as (i += 1); which is it?

Both operations:

Increase i by 1

Return the new value of i

Example:

i = 5;
j = ++i;

Step:

i becomes 6

expression value = 6

So:

j = 6

Now compare with:

i = 5;

Step:

i becomes 6

expression value = 6

j = 6

Why i++ is different

i++ (post-increment) returns the old value first.

Example:

i = 5;
j = i++;

Steps:

expression value = 5

then i becomes 6

So:

j = 5
i = 6

j = 6
i = 6

| Expression | Returned Value | Final `i`   |
| ---------- | -------------- | ----------- |
| `++i`      | new value      | incremented |
| `i++`      | old value      | incremented |

Therefore:

++i is exactly equivalent to (i += 1), while i++ is not.

```c
case 0: printf("zero");
case 1: printf("one");
case 2: printf("two");
}
```

</Question>
<Answer>

Step 1: Evaluate the switch expression
```
i % 3 = 1 % 3 = 1
```
So the switch will jump to case 1.

Step 2: Check for break statements
- Important: There are no break statements in any case. 
- In C, switch statements “fall through” when there is no break. 
- That means after executing case 1, it will continue executing case 2 and any code after that until the end of the switch.

Step 3: Determine what is printed
1. **case 1**: printf("one"); → prints "one" 
2. **Falls through to case 2**: printf("two"); → prints "two" 
3. case 0 is skipped because we jumped directly to case 1.

Final Output
```
onetwo
```

Key Notes
- Without break, all subsequent cases execute after the matched case → this is called fall-through. 
- To prevent fall-through, always use break if you don’t want the subsequent cases executed: 
```c
switch (i % 3) {
    case 0: printf("zero"); break;
    case 1: printf("one"); break;
    case 2: printf("two"); break;
}
```
- Then the output would just be "one".
