
# 🧪 Hands-on Lab Exercises (Structured Expansion)

Below is a **clean extended lab plan per OS section** so you can scale the project into a full training curriculum.

---

## 1. Linux Architecture Labs

* Inspect kernel version: `uname -a`
* Explore `/proc/version`, `/proc/cpuinfo`
* Trace system calls using `strace ls`
* Boot process analysis with `dmesg`

---

## 2. Process Management Labs

* Write C program using `fork()`
* Create zombie & orphan processes
* Use `ps`, `top`, `htop` to analyze processes
* Compare `fork()` vs `exec()` behavior
* Experiment with `nice` and priority changes

---

## 3. Memory Management Labs

* Allocate large heap memory in C and observe behavior
* Inspect memory layout using `/proc/self/maps`
* Trigger and analyze OOM killer scenario (safe simulation)
* Compare stack vs heap allocation patterns

---

## 4. File Systems Labs

* Explore inode using `ls -i`
* Create hard links and symbolic links
* Modify permissions (`chmod`, `umask`)
* Mount/unmount a virtual filesystem (loop device)
* Analyze disk usage with `df` and `du`

---

## 5. Concurrency Labs

* Create race condition using pthreads
* Fix race using mutex locks
* Implement producer-consumer problem
* Experiment with deadlock scenario and detection
* Compare mutex vs spinlock behavior

---

## 6. I/O System Labs

* Open/read/write files using system calls (`open`, `read`, `write`)
* Compare buffered vs unbuffered I/O
* Build simple epoll-based event loop
* Observe file descriptor limits (`ulimit -n`)

---

## 7. Networking Labs

* Build TCP client-server in C or Python
* Inspect network connections with `ss` / `netstat`
* Capture packets using `tcpdump`
* Explore network namespaces
* Test DNS resolution flow

---

## 8. Security Labs

* Modify file permissions and observe access control
* Create users and groups
* Experiment with sudo privileges
* Explore SELinux/AppArmor modes
* Analyze capability restrictions

---

## 9. Virtualization & Containers Labs

* Create and inspect namespaces
* Use `cgroups` to limit CPU/memory usage
* Run Docker containers and inspect isolation
* Compare VM vs container resource usage

---

## 10. Performance Labs

* Profile CPU usage using `top`, `htop`
* Analyze memory leaks
* Measure disk I/O with `iostat`
* Tune system parameters using `sysctl`

---

## 11. Kernel Internals Labs

* Load/unload kernel modules (`insmod`, `rmmod`)
* Explore `dmesg` logs
* Use `perf` for function tracing
* Basic eBPF tracing experiments

---

## 12. Shell Labs

* Build pipelines using `|`
* Redirect input/output (`>`, `<`, `>>`)
* Write bash scripts with loops and conditionals
* Implement simple automation scripts

---

## 13. System Programming Labs

* Use `mmap()` for file mapping
* Send/handle signals (`kill`, `signal`)
* Build multithreaded program using pthreads
* Implement custom memory allocator (basic)

---

## 14. Distributed Systems Labs

* Simulate distributed file access (NFS conceptually)
* Test time sync using `ntpdate`
* Build simple distributed client-server model
* Explore failure handling scenarios

---
