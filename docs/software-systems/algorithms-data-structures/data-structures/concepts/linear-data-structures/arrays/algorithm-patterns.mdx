**Array algorithm patterns(Array Algorithm Patterns)** are standard problem-solving techniques used when working with arrays.


Instead of inventing a new algorithm every time, many array problems can be solved using a small set of recurring strategies (patterns).

So in algorithmic thinking:

 Array patterns = reusable algorithmic templates for solving array problems efficiently.

They help convert a naive O(n²) solution into an efficient O(n) or O(n log n) solution.

**Array algorithm patterns** are standard algorithmic strategies used to solve common array problems efficiently, often reducing time complexity from quadratic to linear or logarithmic.

When you see an array problem, the key question is: Which pattern fits this problem? Because once you recognize the pattern, the algorithm becomes almost mechanical.

Example:

Problem: Find the maximum sum subarray

Recognizing pattern: → Kadane’s Algorithm

Complexity improvement:
- Naive solution: O(n²)
- Kadane algorithm: O(n)

## Most Important Array Algorithm Patterns

These are the core patterns used in algorithm design.
| Pattern                | Main Idea                            | Typical Complexity |
| ---------------------- | ------------------------------------ | ------------------ |
| Traversal              | Scan elements sequentially           | O(n)               |
| Two Pointers           | Use two indices moving through array | O(n)               |
| Sliding Window         | Maintain dynamic subarray window     | O(n)               |
| Prefix Sum             | Precompute cumulative sums           | O(n)               |
| Difference Array       | Efficient range updates              | O(n)               |
| Binary Search on Array | Divide search space                  | O(log n)           |
| Kadane Algorithm       | Max/min subarray problems            | O(n)               |
| Hashing with Arrays    | Frequency counting                   | O(n)               |
| Partition Pattern      | Rearranging elements                 | O(n)               |
| Monotonic Stack/Queue  | Maintain ordered structure           | O(n)               |

These patterns solve a large percentage of array problems.

## Traversal Pattern
Traversal means visiting every element of an array sequentially to perform some operation.

Formal idea: Process each element exactly once in order

Example problem: Find the maximum element.

Basic form:
```
A[0], A[1], A[2], ... , A[n-1]
```
This is the simplest algorithmic pattern for arrays.

Traversal means: Visiting each element in an array (or collection) one by one to perform some operation.

In simple terms: Go through the array from start to end, Process each element.

Structure:
```
initialize state
for each element
    update state
return result
```
This pattern appears in almost every algorithm.

### Basic Traversal Algorithm
Generic form:
```
for i in range(0, n):
    process(A[i])
```
Example:
```
A = [5,2,4,6,1]

for i in range(len(A)):
    print(A[i])
```
Sequence of access:
```
A[0] → A[1] → A[2] → A[3] → A[4]
```
### Basic Traversal Example
Array
```
A = [3, 7, 2, 9, 5]
```
Traverse it
```
3 → 7 → 2 → 9 → 5
```
C Code
```c
#include <stdio.h>
int main() {
    int A[5] = {3,7,2,9,5};
    for(int i = 0; i < 5; i++) {
        printf("%d\n", A[i]);
    }
    return 0;
}
```
What happens
1. i = 0 → access A[0]
2. i = 1 → access A[1]
3. i = 2 → access A[2]
4. i = 3 → access A[3]
5. i = 4 → access A[4]

**Example: Sum of Array**

Algorithm
```
sum = 0
for each element in array
    sum += element
```
C Implementation
```c
int sum = 0;

for(int i = 0; i < n; i++) {
    sum += A[i];
}
```
Visualization
```
A = [3,7,2,9,5]

sum = 0

sum = 0 + 3 = 3
sum = 3 + 7 = 10
sum = 10 + 2 = 12
sum = 12 + 9 = 21
sum = 21 + 5 = 26
```
Result: `sum = 26`

### Complexity

Traversal complexity depends on array size.

For array size n:

Time = O(n)

because every element is visited once.

Space = O(1)

Only one pass.

### Use cases
Traversal Is the Foundation of Many Algorithms

Many simple algorithms are just special cases of traversal.

| Problem         | Operation during traversal |
| --------------- | -------------------------- |
| Find sum        | accumulate values          |
| Find maximum    | compare values             |
| Count elements  | increment counter          |
| Search element  | check condition            |
| Transform array | update values              |


So traversal = scan + operation.

#### Find Maximum/Minimum

Array: [5,2,9,4]

Algorithm:
```
max_val = A[0]

for i in range(1,n):
    if A[i] > max_val:
        max_val = A[i]
```
Step-by-step:
| i | value | max |
| - | ----- | --- |
| 0 | 5     | 5   |
| 1 | 2     | 5   |
| 2 | 9     | 9   |
| 3 | 4     | 9   |


Result: `max = 9`

```cpp
            max = x;
        }
```

```rust
    arr.iter().max().copied()
```

Problem: Find element x.

Array: [8,3,7,1,6]

### Pointer Traversal (Low-Level)
Instead of indices, traversal can use pointer movement.

Conceptually:
```
pointer → pointer+1 → pointer+2
```
Example idea:
```
int *p = A;

for(int i=0;i<n;i++)
{
    process(*p);
    p++;
}
```
This is how compilers often optimize loops.

### Traversal Variations
Traversal can take several forms.
| Type                   | Description                         |
| ---------------------- | ----------------------------------- |
| Simple traversal       | visit each element                  |
| Conditional traversal  | process elements matching condition |
| Accumulation traversal | compute sum/product                 |
| Transform traversal    | modify elements                     |
| Search traversal       | stop when element found             |

### Visualization

### Why Traversal Is Important
Traversal is the base pattern for many more complex patterns. Many patterns start with traversal and add something extra.

Examples:
| Pattern         | How it extends traversal       |
| --------------- | ------------------------------ |
| Two pointers    | two simultaneous traversals    |
| Sliding window  | traversal + dynamic window     |
| Prefix sum      | traversal + cumulative storage |
| Kadane          | traversal + dynamic state      |
| Monotonic stack | traversal + stack structure    |

So traversal is the core scanning mechanism.

### Traversal Variants
1. **Single-Pass Traversal (One Scan)**

The most common pattern. You go through the array once and compute the result during the scan.

Template
```c
for(int i = 0; i < n; i++) {
    process(A[i]);
}
```
Example Uses
- Sum of array
- Find max
- Count elements
- Linear search

Example: Find max
```c
int max = A[0];
for(int i = 1; i < n; i++)
{
    if(A[i] > max)
        max = A[i];
}
```
Complexity
- Time: O(n)
- Memory: O(1)

This is the most efficient possible traversal.

2. **Double-Pass Traversal**

The array is scanned twice. Sometimes the algorithm needs information from the first pass to complete the second pass.

Example Problem: Normalize values.
1. Step 1 → find max
2. Step 2 → divide each element by max

Code
```c
int max = A[0];
for(int i=1;i<n;i++)
    if(A[i] > max)
        max = A[i];
for(int i=0;i<n;i++)
    A[i] = A[i] / max;
```
Complexity
- Time: O(2n) → O(n)
- Memory: O(1)

Still linear.

3. **Bidirectional Traversal (Two-Pointer)**

Traversal from both ends simultaneously. Very powerful pattern.

Visualization
```
[ 3 7 2 9 5 ]
 L         R
```
Pointers move toward each other.

Example Problem: Reverse array
```c
int left = 0;
int right = n - 1;
while(left < right)
{
    int temp = A[left];
    A[left] = A[right];
    A[right] = temp;
    left++;
    right--;
}
```
Used In
- Reverse array
- Two-sum (sorted arrays)
- Palindrome check
- Partition algorithms

4. **Sliding Window Traversal**

Traversal using a moving window over the array. Instead of examining elements individually, we examine groups of elements.

Visualization
```
Window size = 3
[1 2 3] 4 5 6
 1 [2 3 4] 5 6
 1 2 [3 4 5] 6
```
Example: Maximum sum of subarray of size k
```c
int sum = 0;
for(int i=0;i<k;i++)
    sum += A[i];
int max = sum;
for(int i=k;i<n;i++)
{
    sum += A[i];
    sum -= A[i-k];
    if(sum > max)
        max = sum;
}
```
Complexity
- Time: O(n) instead of O(n²).

This is a major optimization technique.

5. **Layered Traversal (Nested Traversal)**

Traversal inside traversal.

Structure
```c
for(i=0;i<n;i++)
{
    for(j=i+1;j<n;j++)
    {
        process(A[i],A[j]);
    }
}
```
Example: All pairs in array.
```
(1,2)
(1,3)
(1,4)
(2,3)
(2,4)
(3,4)
```
Complexity: O(n²)

Used when relationships between elements matter.

6. **Conditional Traversal**

Traversal where elements are processed only if condition matches.

Example: Filter even numbers.
```c
for(int i=0;i<n;i++)
{
    if(A[i] % 2 == 0)
        printf("%d",A[i]);
}
```
Used for:
- Filtering
- Partitioning
- Data selection

7. **Accumulator Traversal (Reduction Pattern)**

Traversal that reduces array to one value.
Examples:
- sum
- max
- min
- product
- count

Template
```c
result = initial_value;
for(i=0;i<n;i++)
    result = combine(result, A[i]);
```
Example:
```c
sum += A[i]
```
This pattern appears in:
- statistics
- machine learning
- database systems
- functional programming

## Two-Pointer Pattern
Use **two indices** moving through the array.

The **Two-Pointer Pattern** is one of the most important array (and string) algorithm techniques. It is essentially a **special traversal strategy using two indices instead of one**.

It is widely used because it can often reduce an `O(n²)` algorithm to `O(n)`.

The idea: Use two indices (pointers) that move through the array according to some rule to solve a problem.

Instead of: `one index → i`, you use: `two indices → left and right`

Example array:
```
[1,2,3,4,6,8,9]
 ^           ^
 i           j
 L           R
```
These pointers move depending on the algorithm. Typical movements:
- both move forward
- one forward, one backward
- one faster than the other

<!--Why It Is Called "Two-Pointer"-->
It Is Called "Two-Pointer", Because you keep two references to elements:
```
A[left]
A[right]
```
and use their relationship to make decisions. Conceptually:
```
compare → update → move pointers
```

Two-Pointer Is Powerful because It avoids nested loops. Instead of:
```
for i
   for j
```
which is: O(n²)

You use:
```
while(left < right)
```
which is: O(n)

When programmers see array problems, they ask: Can I solve this using two moving indices? If yes → try two-pointer pattern.

Typical signals:
- sorted array
- pairs
- subarrays
- partitioning
- symmetry

**Problems That Use Two-Pointer Pattern**

**Common real problems:**
- Reverse array
- Two-sum (sorted array)
- Remove duplicates
- Move zeros to end
- Partition array
- Container with most water
- Trapping rainwater
- Palindrome check
- Merge sorted arrays
- Dutch national flag problem

### Two-Pointer Styles
The Three Main Two-Pointer Styles
#### Opposite Ends (Converging Pointers)
Pointers start at both ends and move toward each other.
```
left  → →
← ←  right
```
Example:
```
[1,2,3,4,5]
L       R
```
Used for:
- reversing arrays
- palindrome checking
- two-sum in sorted arrays
- partitioning

```c
{
    int temp = A[left];
    A[left] = A[right];
    A[right] = temp;
    left++;
    right--;
}
```
Time complexity: O(n)

##### Two-Sum (Sorted Array)
Find two numbers in a sorted array that sum to a target value.

Example:
```
A = [2,7,11,15]
target = 9
```
Result:
```
[2,7] at indices [0,1]
```
Algorithm:
```
left = 0
right = n - 1

while left < right:
    sum = A[left] + A[right]
    if sum == target:
        return [left, right]
    elif sum < target:
        left++
    else:
        right--
```

```c
#include <stdio.h>

void twoSum(int arr[], int size, int target) {
    int left = 0;
    int right = size - 1;
    int found = 0;

    while (left < right) {
        int sum = arr[left] + arr[right];

        if (sum == target) {
            printf("Found: arr[%d] + arr[%d] = %d + %d = %d\n", left, right, arr[left], arr[right], sum);
```

##### Palindrome Check
Check if an array or string is a palindrome using bidirectional traversal.

Example:

```

right = n - 1

while left < right:

    left++
    right--

return true
```

```c
#include <stdio.h>

int isPalindrome(int arr[], int size) {
    int left = 0;
    int right = size - 1;

    while (left < right) {
        if (arr[left] != arr[right]) {
            return 0;
        }
        left++;
        right--;
    }

    return 1;
}
```

##### Partition Algorithm
Partition an array around a pivot value using bidirectional traversal (similar to QuickSort partition).

Example:
```
A = [9,3,7,1,6,2]
pivot = 6
```
Result:
```
[3,1,2,6,9,7] (elements < 6 on left, >= 6 on right)
```
Algorithm:
```
left = 0
right = n - 1

while left <= right:
    while A[left] < pivot:
        left++
    while A[right] >= pivot:
        right--

    if left < right:
        swap(A[left], A[right])
        left++
        right--
```

```c
void partition(int arr[], int size, int pivot) {
    int left = 0;
    int right = size - 1;

    while (left <= right) {
        while (left <= right && arr[left] < pivot) {
            left++;
        }
        while (left <= right && arr[right] >= pivot) {
            right--;

        if (left < right) {
            int temp = arr[left];
            arr[left] = arr[right];
            arr[right] = temp;
            left++;
            right--;
        }
    }
}
```

```rust
fn partition(arr: &mut [i32], pivot: i32) {
    let mut left = 0;
    let mut right = arr.len() - 1;

    loop {
        while left <= right && arr[left] < pivot {
            left += 1;
        }
        while left <= right && arr[right] >= pivot {
            if right == 0 {
                break;
            }
            right -= 1;
        }

        if left < right {
            arr.swap(left, right);
            left += 1;
            right -= 1;
        } else {
            break;
        }
    }
}
```

#### Same Direction (Fast & Slow Pointers)
Both pointers move forward, but at different speeds.
```
slow →
fast  → → → →
```
Example:
```
[1,1,2,2,3,3,4]
 s
 f
```
Generic Template
```
slow = 0;

for(fast = 0; fast < n; fast++)
{
if(condition)
{
A[slow] = A[fast];
slow++;
}
}
```
This template solves many array transformation problems.

Used for:
- removing duplicates
- partitioning
- detecting patterns

The fast/slow technique is really a stream processing algorithm:
```
input stream → fast pointer
output stream → slow pointer
```
Which is why it appears in:
- compression
- filtering
- partitioning
- deduplication
- memory-efficient algorithms

Same-direction two pointers are mainly used for:
| Use case          | Example             |
| ----------------- | ------------------- |
| Remove duplicates | sorted arrays       |
| Remove elements   | filtering           |
| Partition arrays  | quicksort           |
| Move zeros        | rearrangement       |
| Detect cycles     | Floyd algorithm     |
| Compression       | run-length encoding |

Array: `[1,1,2,2,3]`

Goal: `[1,2,3]`

```c
int j = 0;
for(int i = 1; i < n; i++)
{

        A[j] = A[i];
    }
}
```
Pointers:
- j = slow pointer

```c
#include <stdio.h>

int removeDuplicates(int arr[], int size) {
    if (size == 0) return 0;

    int slow = 0;
    for (int fast = 1; fast < size; fast++) {
        if (arr[fast] != arr[slow]) {
            slow++;
            arr[slow] = arr[fast];
        }
    }

    return slow + 1;
}
```

```
A = [1,2,3,4,5]
```


```
slow = 0
fast = 0

while fast < n and fast.next < n:
    slow = slow.next
    fast = fast.next.next

return slow
```

##### Detect Cycle in Array (Floyd's Cycle Detection)

Detect if there is a cycle in an array using Floyd's cycle detection algorithm (tortoise and hare).

Example:
```
A = [1,3,4,2,2]
where A[i] represents next index
```
Result:
```
Cycle detected at value 2
```
Algorithm:
```
slow = fast = A[0]

while true:
    slow = A[slow]
    fast = A[A[fast]]

    if slow == fast:
        return true (cycle exists)
```

<Tabs>
  <TabItem value="c" label="C" default>

```c
#include <stdio.h>

int detectCycle(int arr[], int size) {
    if (size <= 1) return 0;

    int slow = arr[0];
    int fast = arr[0];

    do {
        slow = arr[slow];
        fast = arr[arr[fast]];
    } while (slow != fast && slow < size && fast < size);

    if (slow == fast) {
        return 1;
    }

    return 0;
}

int main() {
    // Test case 1: Cycle detected
    int arr1[] = {1, 3, 4, 2, 2};
    int size1 = 5;

    printf("Array 1: ");
    for (int i = 0; i < size1; i++) printf("%d ", arr1[i]);
    printf("\nCycle detected: %s\n\n", detectCycle(arr1, size1) ? "Yes" : "No");

    // Test case 2: No cycle
    int arr2[] = {0, 1, 2, 3, 4};
    int size2 = 5;

    printf("Array 2: ");
    for (int i = 0; i < size2; i++) printf("%d ", arr2[i]);
    printf("\nCycle detected: %s\n\n", detectCycle(arr2, size2) ? "Yes" : "No");

    int size4 = 5;

    return 0;
}
```

```rust
fn detect_cycle(arr: &[i32]) -> bool {
    if arr.len() <= 1 {
        return false;
    }

    let mut slow = arr[0] as usize;
    let mut fast = arr[0] as usize;

    loop {
        slow = arr[slow] as usize;
        fast = arr[arr[fast] as usize] as usize;

        if slow == fast {
            return true;
        }

        if slow >= arr.len() || fast >= arr.len() {
            return false;
        }
    }
}
```

#### Sliding Window (Moving Range)
Two pointers define a window.
```
left → window start
right → window end
```
Example:
```
[1,2,3,4,5]
L   R
```
Window grows and shrinks.

Used for:
- subarray problems
- longest substring
- maximum sum subarray

Example: max sum subarray of size k

**Example — Two Sum (Sorted Array)**

- Given: A = [1,2,4,6,10]
- target = 8

Find two numbers that sum to 8.

Start:
```
L = 1
R = 10
1 + 10 = 11 → too big → move right
1 + 6 = 7 → too small → move left
2 + 6 = 8 → found
```
Code:
```
int left = 0;
int right = n - 1;

while(left < right)
{
    int sum = A[left] + A[right];

    if(sum == target)
        return 1;

    if(sum < target)
        left++;
    else
        right--;
}
```
Step 1
```
L       R
1 2 4 6 10
```
Step 2
```
L     R
1 2 4 6 10
```
Step 3
```
  L   R
1 2 4 6 10
```
Match found.

Time complexity: O(n)

Without two pointers: O(n²)

## Sliding Window Pattern
Used for **subarray problems**.

Idea: Maintain a window that moves across the array.

Example:
```
A = [2,1,5,1,3,2]
Window size = 3
```
Windows:
```
[2,1,5]
[1,5,1]
[5,1,3]
[1,3,2]
```
Instead of recomputing each sum: Update incrementally.

Example:
```
sum = sum - left + right
```
Complexity: O(n)

Used for:
- maximum subarray of size k
- longest substring
- smallest subarray with condition

## Prefix Sum Pattern
Used when we need **fast range queries**.

Example:
```
A = [3,1,4,2,5]
```
Build prefix sum
```
P = [3,4,8,10,15]
```
Then:
```
sum(i,j) = P[j] - P[i-1]
```
Example:
```
sum(2,4) = 10 - 3 = 7
```
- Without prefix sums: O(n) per query
- With prefix sums: O(1)

## Difference Array Pattern
Used for **efficient range updates**.

Example problem: Add `+5` to every element in range `[l,r]`.

Instead of updating all elements: Use difference array.

Idea:
```
D[l] += 5
D[r+1] -= 5
```
Then compute prefix sums.

This reduces multiple range updates from: O(n*m) → O(n+m)

## Binary Search Pattern
Works on **sorted arrays**.

Idea: Divide search space in half.

Example: A = [1,3,5,7,9,11]

Search for 7.

Steps:
1. mid = (low+high)/2
2. Compare A[mid] with target
3. Adjust search space

Time complexity: O(log n)

## Kadane’s Algorithm

Used for: **Maximum Subarray Sum**

Example: `A = [-2,1,-3,4,-1,2,1,-5,4]`

Best subarray: [4,-1,2,1] = 6

Kadane idea:
```
current = max(A[i], current + A[i])
best = max(best, current)
```
Complexity: O(n)

## Partition Pattern
Used in:
- QuickSort
- QuickSelect

Example: `[9,3,7,1,6,2]`
- pivot = 6
- Partition result: `[3,1,2 | 6 | 9,7]`
- Left < pivot
- Right > pivot

Complexity: O(n)

## Monotonic Stack / Queue
Used for next greater element problems.

Example: `A = [2,1,2,4,3]`

Find next greater element.

Result: `[4,2,4,-1,-1]`

Stack keeps elements in monotonic order.

Complexity: O(n)

1. Find Maximum Element

Example:
```
A = [3,7,2,9,5]
```
Algorithm:
```
max_val = A[0]

for x in A:
    if x > max_val:
        max_val = x
```
Pattern: Traversal

Complexity: O(n)

2. Two Sum Problem

Problem: Find two numbers that sum to target.

Example:
- A = [2,7,11,15]
- target = 9

Answer:
```
2 + 7 = 9
```
Patterns: Hashing version

O(n)

Two pointers version (sorted array)
```
i = 0
j = n-1
```

3. Remove Duplicates from Sorted Array

Example:
```
[1,1,2,2,3,4,4]
```
Result:
```
[1,2,3,4]
```
Technique: Two pointers:
```
slow pointer → unique elements
fast pointer → scan array
```

4. Move Zeros to End

Example:
```
[0,1,0,3,12]
```
Result:
```
[1,3,12,0,0]
```
Technique: Two pointers:
```
left → position for next non-zero
right → scanning pointer
```
5. Maximum Subarray Sum

Example:
```
[-2,1,-3,4,-1,2,1,-5,4]
```
Best subarray:
```
[4,-1,2,1] = 6
```
Pattern: Kadane Algorithm

Idea:
```
current = max(A[i], current + A[i])
best = max(best, current)
```
Complexity: O(n)

Windows:

```
[2,1,5] = 8
[1,5,1] = 7

[1,3,2] = 6
```

7. Longest Subarray With Condition

Example: Find longest subarray with sum ≤ K.

Pattern: Sliding Window (variable size)

Pattern: Prefix Sum

Algorithm:

```
mid = (low + high)/2
```

Pattern: Binary Search

```
pivot = 6
```

After partition:
