## printf
The f in scanf, like the f in printf, stands for “formatted”; both scanf and printf require the use of a format string to specify the appearance
of the input or output data.

`printf` is used for formatted output:
```c
printf("Hello, %s!", "World");
```
We can used printf to display a string literal—a series of characters enclosed in double
quotation marks. When printf displays a string literal, it doesn’t show the quotation marks.

We can use printf to display the current value of a variable. For example, to
write the message
```
Height: h
```
where h is the current value of the height variable, we’d use the following call of printf:
```c
printf("Height: %d\n", height);
```
1. %d is a placeholder indicating where the value of height is to be filled in during
printing.
2. Note the placement of \n just after %d, so that printf will advance to
the next line after printing the value of height.

There’s no limit to the number of variables that can be printed by a single call
of printf. To display the values of both the height and length variables, we
could use the following call of printf:
```c
printf("Height: %d Length: %d\n", height, length);
```

### Formmating Floats
%d works only for int variables; to print a float variable, we’d use %f
instead.

By default, %f displays a number with six digits after the decimal point.
To force %f to display p digits after the decimal point, we can put .p between %
and f. For example, to print the line
```
Profit: $2150.48
```
we’d use the following call of printf:
```c
printf("Profit: $%.2f\n", profit);
```
where profit is a float variable.

### New-line Character
printf doesn’t automatically advance to the next output line when it finishes printing. To instruct printf to advance one line, we must include \n (the new-line character) in the string to be printed. Writing a new-line character terminates the current output line; subsequent output goes onto the next line.

consider the effect of replacing the statement
```c
printf("To C, or not to C: that is the question.\n");
```
by two calls of printf:
```c
printf("To C, or not to C: ");
printf("that is the question.\n");
```
The first call of printf writes To C, or not to C: . The second call writes
that is the question. and advances to the next line. The net effect is the
same as the original printf—the user can’t tell the difference.

The new-line character can appear more than once in a string literal. To dis-
play the message
```
Brevity is the soul of wit.
  --Shakespeare
```
we could write
```c
printf("Brevity is the soul of wit.\n  --Shakespeare\n");
```

### Printing Expressions
printf can display the value of any numeric expression.

For instance, the statements
```c
volume = height * length * width;
printf("%d\n", volume);
```
could be replaced by
```c
printf("%d\n", height * length * width);
```
printf’s ability to print expressions illustrates one of C’s general principles: **Wherever a value is needed, any expression of the same type will do**.

## scanf
To obtain input, we’ll use the scanf function, the C library’s counterpart to printf.

 scanf needs to know what form the input data will take, just as printf needs to know how to display output data.
`scanf` is used for formatted input:
```c
int age;
scanf("%d", &age);
```

**To read an int value**, we’d use scanf as follows:
```c
scanf("%d", &i); /* reads an integer; stores into i */
```
The "%d" string tells scanf to read input that represents an integer; i is an int variable into which we want scanf to store the input.

**Reading a float value** requires a slightly different call of scanf:
```c
scanf("%f", &x); /* reads a float value; stores into x */
```
%f works only with variables of type float, so it's assuming that x is a float variable. The "%f" string tells scanf to look for an input value in float format (the number may contain a decimal point, but doesn’t have to).

A message that asks the user to enter input (a prompt) normally shouldn’t end with a new-line character, because we want the user to enter input on the same line as
the prompt itself. When the user presses the Enter key, the cursor automatically moves to the next line—the program doesn’t need to display a new-line character
to terminate the current line.

```c
int height, length, width, volume, weight;
printf("Enter height of box: ");
scanf("%d", &height);
```
