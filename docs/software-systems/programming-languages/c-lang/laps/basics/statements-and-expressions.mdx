## Arithmetic Operators

### Reverse two-digit number

<QandA>
<Question>

Write a program that asks the user to enter a two-digit number, then prints the number with its digits reversed. A session with the program should have the following appearance:

```
Enter a two-digit number: 28
The reversal is: 82
```

Read the number using `%d`, then break it into two digits.

Hint: If `n` is an integer, then `n % 10` is the last digit in `n` and `n / 10` is `n` with the last digit removed.

</Question>
<Answer>

```c
#include <stdio.h>

int main() {
  int num, tens, ones;

  printf("Enter a two-digit number: ");
  scanf("%d", &num);

  tens = num / 10; // first digit
  ones = num % 10; // second digit

  printf("The reversal is: %d%d\n", ones, tens);

  return 0;
}
```

How it works

1. The user enters a number (example: 28).
2. num / 10 gets the first digit (2).
3. num % 10 gets the second digit (8).
4. Printing ones then tens reverses the digits.

Here is the shorter version of the program without using extra variables:

```c
#include <stdio.h>

int main() {
    int num;

    printf("Enter a two-digit number: ");
    scanf("%d", &num);

    printf("The reversal is: %d%d\n", num % 10, num / 10);

    return 0;
}
```

How it works

If the user enters 286:

- `num % 10` → `6` (ones digit)
- `(num / 10) % 10` → 8 (tens digit)
- `num / 100` → 2 (hundreds digit)

Printing them in reverse order gives 682.

**a version without using arithmetic to split the number into digits**

```c
#include <stdio.h>

int main() {
  int tens, ones;

  printf("Enter a two-digit number: ");
  scanf("%1d%1d", &tens, &ones);

  printf("The reversal is: %d%d\n", ones, tens);

  // Reverse the digits
  int reversed = ones * 10 + tens;

  printf("The reversal is: %d\n", reversed);
  return 0;
}
```

How it works

1. `%1d` tells scanf to read exactly one digit as an integer.
2. `tens` gets the first digit, `ones` gets the second.
3. Multiply `ones` by 10 and add `tens` → reversed integer.

</Answer>
</QandA>

### Reverse three-digit number

<QandA>
<Question>

Write a program that asks the user to enter a three-digit number, then prints the number with its digits reversed. A session with the program should have the following appearance:

```
Enter a three-digit number: 289
The reversal is: 982
```

Read the number using `%d`, then break it into two digits.

Hint: If `n` is an integer, then `n % 10` is the last digit in `n` and `n / 10` is `n` with the last digit removed.

</Question>
<Answer>

```c
#include <stdio.h>

int main() {
    int num;
    int hundreds, tens, ones;

    printf("Enter a three-digit number: ");
    scanf("%d", &num);

    hundreds = num / 100;        // first digit
    tens = (num / 10) % 10;      // middle digit
    ones = num % 10;             // last digit

    printf("The reversal is: %d%d%d\n", ones, tens, hundreds);

    return 0;
}
```

</Answer>
</QandA>

### Reverse any number of digits

<QandA>
<Question>

Write a program that asks the user to enter a number, then prints the number with its digits reversed. A session with the program should have the following appearance:

```
Enter a number: 289
The reversal is: 982
```

</Question>
<Answer>

```c
#include <stdio.h>

int main() {
  int num, reversed = 0;

  printf("Enter a number: ");
  scanf("%d", &num);

  while (num != 0) {
    reversed = reversed * 10 + num % 10; // add last digit
    num = num / 10;                      // remove last digit
  }

  printf("The reversal is: %d\n", reversed);

  return 0;
}
```

**How it works**

1. `num % 10` gets the last digit.
2. `reversed * 10` shifts the digits left.
3. Add the extracted digit to reversed.
4. `num / 10` removes the last digit.
5. Repeat until `num` becomes `0`.

**step-by-step**

Let’s walk through how the loop reverses 286 step by step.

We have:

```
num = 286
reversed = 0
```

Loop Iteration Table
| Step | `num % 10` (last digit) | `reversed * 10 + last digit` | New `reversed` | `num / 10` (updated num) |
| ---- | ----------------------- | ---------------------------- | -------------- | ------------------------ |
| 1 | 286 % 10 = 6 | 0 _ 10 + 6 = 6 | 6 | 286 / 10 = 28 |
| 2 | 28 % 10 = 8 | 6 _ 10 + 8 = 68 | 68 | 28 / 10 = 2 |
| 3 | 2 % 10 = 2 | 68 \* 10 + 2 = 682 | 682 | 2 / 10 = 0 |

Loop stops because num is now 0.

Final reversed number: 682

**A shorter version that uses just one while loop and minimal variables**:

```c
#include <stdio.h>

int main() {
    int num, rev = 0;

    printf("Enter a number: ");
    scanf("%d", &num);

    while (num != 0)
        rev = rev * 10 + num % 10, num /= 10;

    printf("The reversal is: %d\n", rev);

    return 0;
}
```

**How it works**

- `rev = rev * 10 + num % 10` → adds the last digit of num to rev.
- `num /= 10` → removes the last digit from num.
- The comma operator lets us put both operations in a single line.

</Answer>
</QandA>

### Reverse Negative Number

<QandA>
<Question>

Write a program that asks the user to enter a negative number, then prints the number with its digits reversed. A session with the program should have the following appearance:

```
Enter a number: -289
The reversal is: -982
```

</Question>
<Answer>

```c
#include <stdio.h>

int main() {
  int num, reversed = 0;

  printf("Enter a number: ");
  scanf("%d", &num);

  while (num != 0) {
    reversed = reversed * 10 + num % 10; // add last digit
    num = num / 10;                      // remove last digit
  }

  printf("The reversal is: %d\n", reversed);

  return 0;
}
```

**How it works**

1. If the number is negative, store sign = -1 and work with the absolute value.
2. Reverse digits as before using % 10 and / 10.
3. Multiply the result by sign to restore negative numbers.

This handles any integer, positive or negative, with any number of digits.

### Convert Integer to Octal

<QandA>
<Question>

Write a program that reads an integer entered by the user and displays it in octal (base 8):

```
Enter a number between 0 and 32767: 1953
In octal, your number is: 03641
```

The output should be displayed using five digits, even if fewer digits are sufficient.

Hint: To convert the number to octal,

1. first divide it by 8; the remainder is the last digit of the octal number (1, in this case).
2. Then divide the original number by 8 and repeat the process to arrive at the next-to-last digit.

(printf is capable of displaying numbers in base 8, so there’s actually an easier way to write this program.)

</Question>
<Answer>

```c
#include <stdio.h>

int main(void) {
  int decimal, octal = 0, place = 1, remainder = 0;

  printf("Enter a number between 0 and 32767: ");
  scanf("%d", &decimal);

  while (decimal > 0) {
    remainder = decimal % 8;
    decimal = decimal / 8;
    octal = octal + remainder * place;
    place = place * 10;
  }
  printf("In octal, your number is: %05d\n", octal);

  return 0;
}
```

**a very short version**
```c
#include <stdio.h>


int main() {
    int num, octal = 0, place = 1;

    printf("Enter a number between 0 and 32767: ");
    scanf("%d", &num);

    while (num > 0) {
        octal += (num % 8) * place;
        num /= 8;
        place *= 10;
    }

    printf("In octal, your number is: %d\n", octal);

    return 0;
}
```

How it works

1. `num % 8` gets the octal digit.
2. `num /= 8` removes the last part of the number.
3. `place *= 10` shifts the digit position in the result.
4. The octal number is built in the variable octal.

</Answer>
</QandA>

### European Article Number (EAN) Check Digit

<QandA>
<Question>

European countries use a 13-digit code, known as a European Article Number (EAN)
instead of the 12-digit Universal Product Code (UPC) found in North America. Each EAN
ends with a check digit, just as a UPC does. The technique for calculating the check digit is
also similar:
- Add the second, fourth, sixth, eighth, tenth, and twelfth digits.
- Add the first, third, fifth, seventh, ninth, and eleventh digits.
- Multiply the first sum by 3 and add it to the second sum.
- ubtract 1 from the total.
- Compute the remainder when the adjusted total is divided by 10.
- Subtract the remainder from 9.

For example, consider Güllüoglu Turkish Delight Pistachio & Coconut, which has an EAN
of `8691484260008`. 
1. The first sum is `6 + 1 + 8 + 2 + 0 + 0 = 17`, 
2. and the second sum is `8 + 9 + 4 + 4 + 6 + 0 = 31`. 
3. Multiplying the first sum by 3 and adding the second yields 82. 
4. Subtracting 1 gives 81. 
5. The remainder upon dividing by 10 is 1. 
6. When the remainder is subtracted from 9, the result is 8, which matches the last digit of the original code

Your job is to calculates the check digit for an EAN. The user will enter the first 12 digits of the EAN as a single number:
```
Enter the first 12 digits of an EAN: 869148426000
Check digit: 8
```

</Question>
<Answer>

To compute the EAN check digit, we read the first 12 digits one at a time using %1d, calculate the two sums, and then apply the formula given.
```c
#include <stdio.h>
int main() {
  int digit;
  int sum1 = 0, sum2 = 0;
  int i, total, check_digit;

  printf("Enter the first 12 digits of an EAN: ");

  for (i = 1; i <= 12; i++) {
    scanf("%1d", &digit);

    if (i % 2 == 0)
      sum1 += digit; // second, fourth, sixth, ...
    else
      sum2 += digit; // first, third, fifth, ...
  }

  total = sum1 * 3 + sum2;
  total = total - 1;
  check_digit = 9 - (total % 10);

  printf("Check digit: %d\n", check_digit);

  return 0;
}
```
How the program follows the algorithm
1. Read 12 digits individually with %1d.
2. Add even-position digits → sum1.
3. Add odd-position digits → sum2.
4. Compute
   ```
    total = (sum1 * 3) + sum2
   ```
5. Subtract 1 from total.
6. Compute the remainder when dividing by 10.
7. Subtract that remainder from 9 → check digit.

</Answer>
</QandA>

## Calculating a Broker’s Commission
<QandA>
<Question>

When stocks are sold or purchased through a broker, the broker’s commission is
often computed using a sliding scale that depends upon the value of the stocks
traded. Let’s say that a broker charges the amounts shown in the following table:
| Transaction size    | Commission rate |
| :------------------ | :-------------- |
| Under $2,500        | $30 + 1.7%      |
| $2,500–$6,250       | $56 + 0.66%     |
| $6,250–$20,000      | $76 + 0.34%     |
| $20,000–$50,000     | $100 + 0.22%    |
| $50,000–$500,000    | $155 + 0.11%    |
| Over $500,000       | $255 + 0.09%    |

The minimum charge is $39. 

Our next program asks the user to enter the amount of the trade, then displays the amount of the commission:
```
Enter value of trade: 30000
Commission: $166.00
```
</Question>
<Answer>

The heart of the program is a cascaded if statement that determines which range the trade falls into.
```c
/* Calculates a broker's commission */
#include <stdio.h>

int main(void) {
  float commission, value;
  printf("Enter value of trade: ");
  scanf("%f", &value);

  if (value < 2500.00f)
    commission = 30.00f + .017f * value;
  else if (value < 6250.00f)
    commission = 56.00f + .0066f * value;
  else if (value < 20000.00f)
    commission = 76.00f + .0034f * value;
  else if (value < 50000.00f)
    commission = 100.00f + .0022f * value;
  else if (value < 500000.00f)
    commission = 155.00f + .0011f * value;
  else
    commission = 255.00f + .0009f * value;
  if (commission < 39.00f)
    commission = 39.00f;

  printf("Commission: $%.2f\n", commission);

  return 0;
}
```

The cascaded if statement could have been written this way instead (the
changes are indicated in bold):
```c
if (value < 2500.00f)

commission = 30.00f + .017f * value;

else if (**value >= 2500.00f &&** value < 6250.00f)

commission = 56.00f + .0066f * value;

else if (**value >= 6250.00f &&** value < 20000.00f)

commission = 76.00f + .0034f * value;
```
Although the program will still work, the added conditions aren’t necessary. 

For example, the first if clause tests whether value is less than 2500 and, if so, computes the commission. When we reach the second if test (`value >= 2500.00f && value < 6250.00f`), we know that value can’t be less than `2500` and
therefore must be greater than or equal to `2500`. The condition `value >= 2500.00f` will always be true, so there’s no point in checking it.

</Answer>
</QandA>

## Printing a Date in Legal Form

<QandA>
<Question>

Contracts and other legal documents are often dated in the following way:
```
Dated this __________ day of __________ , 20__ .
```
Let’s write a program that displays dates in this form. We’ll have the user enter the
date in `month/day/year` form, then we’ll display the date in "legal" form:
```
Enter date (mm/dd/yy): 7/19/14
Dated this 19th day of July, 2014.
```

</Question>
<Answer>

We can get printf to do most of the formatting. However, we’re left with two
problems: 
1. how to add "th" (or "st" or "nd" or "rd") to the day, 
2. and how to print the month as a word instead of a number. 

Fortunately, the switch statement is ideal
for both situations; we’ll have one switch print the day suffix and another print
the month name.
```c
#include <stdio.h>
int main(void) {
  int month, day, year;
  printf("Enter date (mm/dd/yy): ");
  scanf("%d /%d /%d", &month, &day, &year);
  printf("Dated this %d", day);
  switch (day) {
  case 1:
  case 21:
  case 31:
    printf("st");
    break;
  case 2:
  case 22:
    printf("nd");
    break;
  case 3:
  case 23:
    printf("rd");
    break;
  default:
    printf("th");
    break;
  }
  printf(" day of ");
  switch (month) {
  case 1:
    printf("January");
    break;
  case 2:
    printf("February");
    break;
  case 3:
    printf("March");
    break;
  case 4:
    printf("April");
    break;
  case 5:
    printf("May");
    break;
  case 6:
    printf("June");
    break;
  case 7:
    printf("July");
    break;
  case 8:
    printf("August");
    break;
  case 9:
    printf("September");
    break;
  case 10:
    printf("October");
    break;
  case 11:
    printf("November");
    break;
  case 12:
    printf("December");
    break;
  }
  printf(", 20%.2d.\n", year);
  return 0;
}
```
Note the use of `%.2d` to display the last two digits of the year. If we had used
`%d` instead, single-digit years would be displayed incorrectly (`2005` would be
printed as `205`).
</Answer>
</QandA>
