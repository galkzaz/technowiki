<Question>

If `i` and `j` are positive integers, does `(-i)/j` always have the same value as `-(i/j)`? Justify your answer.

</Question>
<Answer>

Yes. If i and j are positive integers in C (C99 and later), then
$$
(−i)/j=−(i/j)
$$
always holds.

Let’s justify this carefully.

1️⃣ C Integer Division Rule

In C99 and later, integer division truncates toward zero.

That means: a/b

produces the integer closest to zero.

Examples:
```
7 / 3  = 2
-7 / 3 = -2
```
Notice:
```
7 / 3  =  2.333 →  2
-7 / 3 = -2.333 → -2
```
Both results move toward zero.

2️⃣ Let i and j be Positive

Assume:
```
i > 0
j > 0
```

First compute:

i / j

Let

i / j = q

where q is the integer quotient after truncation.

3️⃣ Compute -(i/j)
```
-(i/j) = -q
```
4️⃣ Compute (-i)/j

Now consider:
```
(-i)/j
```
The exact real result is:

$$
-\frac{ij}{j} = −(i/j)
$$

But C truncates toward zero.

Since i/j truncates to q, the real value is:

$$
-(i/j) = -q - (r/j)
$$

where:  $0≤r<1$

Truncating toward zero removes the fractional part:
$$
(-i)/j = -q
$$
5️⃣ Compare Results

We found:

-(i/j) = -q
(-i)/j = -q

So:

(-i)/j == -(i/j)
6️⃣ Example

Let:

i = 7
j = 3

Compute both sides.

Left side
(-7)/3 = -2
Right side
-(7/3)
= -(2)
= -2

They match.

</Answer>
</QandA>

    - Real value: -8/(-5)=1.6

    - C99: **1** (truncates toward 0)

k remains 1.

i *= (j *= k)

i *= 0

1 - 1 = 0

0

2

0 2
(b)
i = 10; j = 5;

10 - 6 = 4

First printf prints:

4
Step 2

Final values:

i = 11
j = 6

Second printf prints:

11 6

✅ Output

Final values:

i = 8
j = 7

<Question>

Only one of the expressions ++i and i++ is exactly the same as (i += 1); which is it?
Justify your answer.

</Question>
<Answer>

The expression that is exactly the same as (i += 1) is:

✅ ++i (pre-increment)

Why ++i is equivalent to (i += 1)

Both operations:

Increase i by 1

Return the new value of i

Example:

i = 5;
j = ++i;

Step:

i becomes 6

expression value = 6

So:

j = 6

Now compare with:

i = 5;
j = (i += 1);

Step:

i becomes 6

expression value = 6

So:

j = 6

Thus ++i behaves exactly like (i += 1).

Why i++ is different

i++ (post-increment) returns the old value first.

Example:

i = 5;
j = i++;

Steps:

expression value = 5

then i becomes 6

So:

j = 5
i = 6

But (i += 1) would give:

j = 6
i = 6

Conclusion
| Expression | Returned Value | Final `i`   |
| ---------- | -------------- | ----------- |
| `++i`      | new value      | incremented |
| `i++`      | old value      | incremented |
| `i += 1`   | new value      | incremented |

Therefore:

++i is exactly equivalent to (i += 1), while i++ is not.

</Answer>

- Unary -b first.

- Then subtraction.
