:::question

This segment of a C program contains the five variables a, b, c, d, and e. 
```c
a = b + c;
d = a − e;
```
The compiler translates from C to RISC-V assembly language instructions.

Show the RISC-V code produced by a compiler.

:::

**Answer:**

A RISC-V instruction operates on two source operands and places the result
in one destination operand. Hence, the two simple statements above compile
directly into these two RISC-V assembly language instructions:
```assembly
add a, b, c
sub d, a, e
```

:::question

Compiling a Complex C Assignment into RISC-V

A somewhat complicated statement contains the five variables f, g, h, i, and j:
```c
f = (g + h) − (i + j);
```
What might a C compiler produce?

:::

**Answer:**

The compiler must break this statement into several assembly instructions,
since only one operation is performed per RISC-V instruction. The first
RISC-V instruction calculates the sum of g and h. We must place the result
somewhere, so the compiler creates a temporary variable, called t0:
```assembly
add t0, g, h // temporary variable t0 contains g + h
```
Although the next operation is subtract, we need to calculate the sum of i and
j before we can subtract. Thus, the second instruction places the sum of i and
j in another temporary variable created by the compiler, called t1:
```assembly
add t1, i, j // temporary variable t1 contains i + j
```
Finally, the subtract instruction subtracts the second sum from the first and
places the difference in the variable f, completing the compiled code:
```assembly
sub f, t0, t1 // f gets t0 − t1, which is (g + h) − (i + j)
```

:::question

For a given function, which programming language likely takes the most lines of
code? Put the three representations below in order.
1. Java
2. C
3. RISC-V assembly language

:::

**Answer:**

For a given function, the number of lines of code generally increases as you move closer to hardware.

Correct Order (Most lines → Fewest lines)
1. RISC-V assembly language
2. C
3. Java

Explanation

RISC-V Assembly Language (Most Lines)

Assembly is very low-level:
- You must manage registers manually
- You must handle function calls explicitly
- You must manage stack frames
- You must move data between memory and registers yourself
- Even simple operations require multiple instructions

Example: Adding two numbers might require:
- Loading arguments
- Performing the addition
- Storing result
- Managing return

Thus, assembly code is typically the longest.

C (Middle)

C is a high-level language but still close to hardware:
- You manage memory manually
- You can directly control data types
- Fewer abstractions than Java

The compiler handles:
- Register allocation
- Stack management
- Calling conventions

So C usually requires fewer lines than assembly, but more than Java.

Java (Fewest Lines)

Java provides:
- Automatic memory management (garbage collection)
- Built-in libraries
- High-level abstractions
- Object-oriented features

Much of the complexity is handled by:
- The compiler
- The Java Virtual Machine (JVM)

Therefore, Java usually requires the fewest lines of code for the same functionality.

General Rule in Computer Architecture

As abstraction level increases:
```
Higher Abstraction → Fewer Lines → Less Hardware Control
Lower Abstraction → More Lines → More Hardware Control
```
Important Note

This is generally true for:
- Typical application-level functions
- Normal structured programs

For extremely small, simple operations, the difference may not be dramatic. But for realistic programs, assembly almost always requires the most code.
