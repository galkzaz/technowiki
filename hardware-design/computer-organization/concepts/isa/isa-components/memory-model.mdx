## Memory Model
The ISA defines how memory behaves.
6.1 Address Space
Defines:
- Maximum memory size
- Virtual vs physical addressing
- 32-bit vs 64-bit addressing

6.2 Load/Store Model
Some ISAs use:
- Load/store only (RISC)
- Memory-to-memory operations (CISC)
This affects:
- Pipeline complexity
- Energy consumption
- Instruction simplicity

6.3 Memory Consistency Model
Defines how memory behaves in multi-core systems.
Important for:
- Parallel programming
- Synchronization
- Atomic instructions
